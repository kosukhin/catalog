# Работа с битами

```javascript
const bitIndex = 22;
// третий байт содержит бит 22
const  byte = bitIndex >> 3;
console.log(byte);
const offset = bitIndex & 7;
// смещение 22 бита внутри байта
console.log(offset)
const mask = 1 << offset; // Маска для бита
console.log(mask.toString(2))
```
