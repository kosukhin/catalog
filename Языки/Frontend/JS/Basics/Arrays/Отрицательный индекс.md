# Пример записи по отрицательному индексу

Если записать в массив значение по отрицательному индексу оно запишется как свойство объекта и не повлияет на массив

```javascript
(() => {
    const buckets = [1, 2, 3];
    buckets[-1] = 'hello'
    console.log(buckets);
    console.log(buckets.length);
    buckets.forEach(console.log)
})();
```
