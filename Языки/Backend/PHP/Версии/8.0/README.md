# PHP 8.0 (выпущена 26.11.2020)

Крупнейший релиз за десятилетие.

## Последние улучшения / новые возможности

- **Named arguments** — именованные аргументы: можно пропускать необязательные параметры.
- **Attributes** — нативные аннотации вместо докблок-аннотаций.
- **Constructor property promotion** — объявление и инициализация свойств прямо в конструкторе.
- **Union types** — объединения типов (`int|string`).
- **Match-выражение** — современная замена switch.
- **Nullsafe-оператор** `?->`.
- **Строгие сравнения строк и чисел** (`"0" == false` теперь false).
- **Стрелочные функции-сортировка с spaceship** и др.
- **static return type**, `::class` на объектах, `str_contains()`, `str_starts_with()`, `str_ends_with()`, JIT-компилятор.

## Запуск

```bash
docker build -t php80-demo .
docker run --rm php80-demo
```
