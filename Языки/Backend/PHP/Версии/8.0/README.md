# PHP 8.0 (выпущена 26.11.2020)

Крупнейший релиз за десятилетие.

## Последние улучшения / новые возможности

- **Named arguments** — именованные аргументы: можно пропускать необязательные параметры.
- **Attributes** — нативные аннотации вместо докблок-аннотаций.
- **Constructor property promotion** — объявление и инициализация свойств прямо в конструкторе.
- **Union types** — объединения типов (`int|string`).
- **Match-выражение** — современная замена switch (подробности ниже).
- **Nullsafe-оператор** `?->`.
- **Строгие сравнения строк и чисел** (`"0" == false` теперь false).
- **Стрелочные функции-сортировка с spaceship** и др.
- __static return type__, `::class` на объектах, `str_contains()`, `str_starts_with()`, `str_ends_with()`, JIT-компилятор.

## Как работает match

`match` — это **выражение**: он возвращает значение, которое можно присвоить переменной. Он по очереди строго сравнивает (`===`) значение в скобках с каждым условием слева от `=>` и возвращает результат первой совпавшей ветки.

```php
$message = match ($code) {
    200, 201 => 'OK',               // несколько значений через запятую
    404      => 'Не найдено',
    default  => 'Неизвестный код',
};
```

Отличия от switch:

- выполняется только одна ветка — нет «проваливания» и не нужен `break`;
- сравнение строгое (`===`), а не свободное (`==`);
- если ничего не совпало и нет `default` — бросается `UnhandledMatchError`.

> ⚠️ Важно: `match` вычисляется **один раз в момент выполнения** и просто возвращает результат. Он не «связывается» с переменной — если позже изменить исходную переменную, уже присвоенное значение не пересчитается (см. пример `match` в `examples.php`).
