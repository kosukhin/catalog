# Catalog

Это репозиторий для обучения и проверки гипотез.

Комиты формируются автоматически с помощью расширения **GitDoc**

Для запуска кода из .md файлов использую **Runme**

Для визуализации использую расширение **Drawio integration**

## Мотивация

Идея в том, что понимание возможно только тогда, когда мы себя испытываем, когда мы пытаемся на основе своего понимания самостоятельно воспроизвести что-то. Испытание - это неотъемлемая часть понимания, не практика не создание рабочего решения с помощью подсказок ИИ, а именно воспроизведение решения на основе своего понимания. ИИ тоже помогает, он проверяет результат дает подсказки, но не думает за меня.
