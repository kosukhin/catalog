# Значения обозначений

Некоторые обозначения в этой книге ещё не стали общепринятыми. Ниже перечислены обозначения, которые могут быть незнакомы читателям, изучавшим аналогичный материал по другим книгам, с указанием страниц, где они объясняются (Р. Грэхем, Д. Кнут, О. Паташник, «Конкретная математика»).

| Обозначение | Название | Стр. |
| --- | --- | --- |
| `ln x` | натуральный логарифм: `log_e x` | 262 |
| `lg x` | двоичный логарифм: `log_2 x` | 70 |
| `log x` | десятичный логарифм: `log_10 x` | 435 |
| `⌊x⌋` | пол: `max{n ∣ n ≤ x, n целое}` | 67 |
| `⌈x⌉` | потолок: `min{n ∣ n ≥ x, n целое}` | 67 |
| `x mod y` | остаток: `x − y⌊x/y⌋` | 82 |
| `{x}` | дробная часть: `x mod 1` | 70 |
| `Σ f(x) δx` | неопределённая сумма | 48 |
| `Σ_a^b f(x) δx` | определённая сумма | 49 |
| `x^{n̲}` | нисходящая факториальная степень: `x!/(x − n)!` | 47 |
| `x^{n̅}` | восходящая факториальная степень: `Γ(x + n)/Γ(x)` | 48 |
| `n¡` | субфакториал: `n!/0! − n!/1! + … + (−1)^n n!/n!` | 194 |
| `ℜz` | действительная часть: `x`, если `z = x + iy` | 64 |
| `ℑz` | мнимая часть: `y`, если `z = x + iy` | 64 |
| `H_n` | гармоническое число: `1/1 + … + 1/n` | 29 |
| `H_n^{(r)}` | обобщённое гармоническое число: `1/1^r + … + 1/n^r` | 263 |
| `f^{(m)}(z)` | `m`-я производная `f` в точке `z` | 456 |
| `(n k)` | биномиальный коэффициент (`n` над `k`) | 154 |
| `[n k]` | число Стирлинга циклического типа («первого рода») | 245 |
| `{n k}` | число Стирлинга подмножеств («второго рода») | 244 |
| `⟨n k⟩` | число Эйлера | 253 |
| `⟨⟨n k⟩⟩` | число Эйлера второго порядка | 256 |
| `(a_n … a_0)_b` | запись числа по основанию `b` (radix) | 11 |
| `K(a_1, …, a_n)` | многочлен-континуант | 288 |
| `F(a_1 … a_m; b_1 … b_n; z)` | гипергеометрическая функция | 205 |
| `#A` | мощность: число элементов множества `A` | 39 |
| `[z^n] f(z)` | коэффициент при `z^n` в `f(z)` | 197 |
| `[α..β]` | замкнутый интервал: множество `{x ∣ α ≤ x ≤ β}` | 73 |
| `[m = n]` | `1`, если `m = n`, иначе `0` | 24 |
| `[m ∖ n]` | `1`, если `m` делит `n`, иначе `0` | 102 |
| `[m ∥ n]` | `1`, если `m` делит `n` ровно (exactly divides), иначе `0` | 146 |
| `[m ⊥ n]` | `1`, если `m` и `n` взаимно просты, иначе `0` | 115 |

> В общем случае, если `S` — любое утверждение, которое может быть истинным или ложным, запись `[S]` означает `1`, если `S` истинно, и `0` в противном случае.

## Примечания

- В книге обозначения `(n k)`, `[n k]`, `{n k}`, `⟨n k⟩`, `⟨⟨n k⟩⟩` записываются «в столбик»: `n` над `k`, в круглых, квадратных, фигурных или угловых скобках.
- Запись `∖` использована вместо обратного слэша `\` (делимость), чтобы не ломать таблицу Markdown; `∥` — вместо двойного слэша `\\` («делит ровно»).
- В тексте книги одинарные кавычки-лапки (‘…’) ограничивают текст, а двойные (“…”) — фразу в речи.
- Выражение вида `a/bc` означает то же, что `a/(bc)`; кроме того, `log x/log y = (log x)/(log y)` и `2n! = 2(n!)`.
