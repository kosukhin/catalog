# Пример работы quadratic probing в HashSet

В этом примере показана работа **quadratic probing** для открытой адресации.
Хеш-таблица сохраняет элементы в массиве `buckets` линейно, а при коллизии
ищет свободное место по квадратической последовательности индексов:

```text
probe(i) = (h1(key) + i^2) % capacity   (c1 = 0, c2 = 1)
```

Таким образом, если по прямому адресу `h1(key) % capacity` уже стоит другой
eлемент, таблица проверяет `1`, `4`, `9`, `16`, `25`, ... шагов от начала.

Ниже приведён полный рабочий пример на C++. Он выводит:

- текущую ёмкость и нагрузку;
- ключи до и после вставки;
- для каждого вставленного ключа цепочку индексов, по которым искалось место;
- пример успешного поиска и удаления;
- пример, когда вставка должна упасть из-за переполнения (load factor > 1).

## Как запустить

```sh
g++ -std=c++17 -O2 -Wall -Wextra -o quadratic_set Примеры.md.cpp
./quadratic_set
```

> В репо есть аналогичный класс на JavaScript в
> `HashSet/HashSetOpenAddressing.js`. Там та же формула выглядит как
> `probe(value, iteration) = (hashFn(value) + probingFn(iteration)) % size`
> при `probingFn(iteration) = iteration * iteration`.

## Важные детали квадратического пробирования

1. **Коллизии решаются последовательным поиском по квадратической
   прогрессии.** Сначала `0`, потом `1`, `4`, `9`, ... (модуль ёмкости).
2. **Достоинство:** редкие коллизии не создают длинных полос, как в
   linear probing.
3. **Недостаток:** при определённых наборах ключей последовательности
   исследования могут не охватить все слоты (например, если `capacity` и
   константа являются степенями двойки, спрямление может зациклиться).
   Поэтому на практике:
   - ёмкость выбирают простым числом или в степень простого;
   - при `loadFactor >= 1` готовы уже к перехэшированию;
   - при вставке сначала делают `find`, чтобы не вставлять дубликаты;
   - при удалении используют флаг `kRemoved`, чтобы обход не останавливался на
     пустом слоте, но при этом продолжал искать удаляемую запись и
     вставляемые элементы могли продолжить probing-поиск далее.
