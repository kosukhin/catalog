# Radix Tree (сжатое префиксное дерево, Patricia trie)

## Что это такое

**Radix Tree** (компактный trie, сжатое префиксное дерево, Patricia trie) —
это вариант префиксного дерева, в котором цепочки узлов, имеющих ровно
одного ребёнка, «схлопываются» в одно ребро, помеченное целой подстрокой
(label).

За счёт этого Radix Tree:

- использует меньше памяти (меньше узлов);
- делает меньше шагов при обходе (перепрыгивает целые подстроки).

## Как устроен

Каждый узел хранит:

- `label` — подстрока на ребре от родителя к этому узлу;
- `children` — отображение «первый символ label ребёнка → узел»;
- `isEndOfWord` — флаг конца слова;
- `value` — необязательное значение.

Дети ключуются по первому символу своего `label`, поэтому найти нужное
ребро можно за O(1), а сравнение подстрок — за длину общего префикса.

## Пример сжатия

Слова `romane` и `romanus` в обычном trie:

```
       root
        |
        r
        |
        o
        |
        m
        |
        a
        |
        n
       / \
      e   u
     (*)  |
          s
         (*)
```

Те же слова в Radix Tree:

```
        root
         |
       roman
        / \
       e   us
      (*)  (*)
```

9 узлов против 4.

## Основные операции и сложность

| Операция | Метод | Сложность |
|----------|-------|-----------|
| Вставка слова | `insert(word)` | O(len(word)) |
| Поиск слова | `search(word)` | O(len(word)) |
| Проверка префикса | `startsWith(prefix)` | O(len(prefix)) |
| Удаление слова | `delete(word)` | O(len(word)) |
| Все слова с префиксом | `wordsWithPrefix(prefix)` | O(len(prefix) + k) |

Главные внутренние операции:

- **Расщепление ребра** при вставке: если новое слово совпадает с ребром
  лишь частично, ребро делится на общий префикс + хвост.
- **Слияние рёбер** при удалении: если узел перестал быть словом и имеет
  одного ребёнка, он объединяется с ним в одно ребро.

## Где применяется

- Маршрутизация в сетях (longest prefix match, таблицы маршрутизации).
- Индексы в СУБД и in-memory хранилищах (например, адаптивные индексы
  в MySQL/InnoDB, Redis Rax для streams).
- Файловые системы и IP-адресация.
- Полнотекстовый поиск и автодополнение с экономией памяти.

## Отличие от обычного trie

| Свойство | Trie | Radix Tree |
|----------|------|------------|
| Узел хранит | один символ | подстроку (label) |
| Число узлов | больше | меньше |
| Память | больше | меньше |
| Скорость обхода | больше шагов | меньше шагов |
| Сложность реализации | проще | сложнее (split/merge) |
