# TreeSetAVL сущности

## Элемент дерева

Основное существо дерева, ради которого дерево и создается.

## Высота поддерева узла

У каждого узла дерева есть объект информирующий о высоте поддерева этого узла.

## Потомок

У каждого узла может быть потомок, потомок может быть слева или справа.

## Родитель

У каждого узла кроме корня должен быть родитель. То есть дерево является двусвязным списком, по элементам можно идти как от корня к листьям так и от листьев к корню.

## Корень или Лидер

Главный узел дерева

## Слот

Позиция в которой у узла есть потомок

## Инвариант связей в слотах

AVL дерево следует инварианту BST то есть если каждый левый узел по значению меньше родителя а каждый правый по значению больше родителя.

## Инвариант удаления узла

При удалении узла придерживаемся правила
