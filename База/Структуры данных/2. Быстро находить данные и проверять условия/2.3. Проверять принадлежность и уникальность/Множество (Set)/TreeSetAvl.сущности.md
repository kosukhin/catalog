# TreeSetAVL сущности

## Элемент дерева

Основное существо дерева, ради которого дерево и создается.

## Высота поддерева узла

У каждого узла дерева есть объект информирующий о высоте поддерева этого узла.

## Потомок

У каждого узла может быть потомок, потомок может быть слева или справа.

## Родитель

У каждого узла кроме корня должен быть родитель. То есть дерево является двусвязным списком, по элементам можно идти как от корня к листьям так и от листьев к корню.

## Корень или Лидер

Главный узел дерева

## Слот

Позиция в которой у узла есть потомок

## Закон связей в слотах

AVL дерево следует инварианту BST то есть если каждый левый узел по значению меньше родителя а каждый правый по значению больше родителя.

Операции:
- Берем узел дерева
- Когда узел равен значению возвращаем что слот текущий узел
- Когда значение меньше узла возвращаем слот левый
- Когда значение больше узла возвращаем слот правый

## Закон расчета высоты поддерева

Смысловая модель:
- Основан на предположении, что все потомки имеют уже рассчитанное верное значение высоты поддерева.
- Вычисляется как максимум из высоты поддерева правого узла или высоты поддерева левого узла +1,
    - Например высота поддерева правого узла 1. высота поддерева левого узла 2
    - Выбираем максимум - 2
    - Прибавляем 1
Высота поддерева всегда минимум 1, потому что учитываем себя.
