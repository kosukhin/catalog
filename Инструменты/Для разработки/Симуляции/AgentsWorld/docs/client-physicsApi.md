# `client/physicsApi.ts` — загрузка состояния физики

Тянет состояние физики с сервера: `loadPhysicsState(url, fetcher)` запрашивает
`/api/physics` и возвращает `PhysicsState`. `fetcher` подменяется в тестах (по
умолчанию — глобальный `fetch`, который бросает исключение на не-2xx).

Тип `PhysicsState` берётся из `agents/physicsAgent.ts` только как тип — в бандл не
попадает.

## Что экспортирует

| Экспорт | Назначение |
|---|---|
| `loadPhysicsState(url, fetcher?)` | загружает и разворачивает состояние физики |
| `PhysicsFetcher` | тип функции загрузки (для подмены в тестах) |

## Тест

`test/physicsApi.test.ts` — загрузка по адресу через подставной `fetcher`,
проброс ошибки загрузки.
