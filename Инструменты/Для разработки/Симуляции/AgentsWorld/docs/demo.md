# `scripts/demo.ts` — демонстрация

Запуск: `npm start` (то же, что `node scripts/demo.ts`).

Скрипт — это **точка сборки мира**: он решает, какие модули агентов подключены и
сколько их. Ядро про агентов ничего не знает.

```js
import * as dayAgent from '../agents/dayAgent.ts';
import * as humanCatalogAgent from '../agents/humanCatalogAgent.ts';
import * as humanAgent from '../agents/humanAgent.ts';

const world = new World(new Map([
    [dayAgent, 1],
    [humanCatalogAgent, 1],
    [humanAgent, 3],
]));
```

Дальше сценарий такой:

1. Запуск: человек регистрируется в каталоге и спрашивает время у `DayAgent`.
2. `DayAgent` отвечает, человек выбирает состояние (ночью спит, днём активен).
3. Скрипт просит `HumanAgent-1` найти всех людей — человек пересылает поиск
   каталогу, каталог отвечает ему же, человек печатает результат.

## Что видно в выводе

```
мир: DayAgent-1, HumanCatalogAgent-1, HumanAgent-1, HumanAgent-2, HumanAgent-3
[HumanAgent-2 · поток 4] я Ольга, женщина, учитель
[HumanCatalogAgent-1 · поток 2] записал в каталог: Ольга (женщина, учитель) → HumanAgent-2
[HumanAgent-1 · поток 3] я Иван, мужчина, врач
[HumanAgent-1 · поток 3] сейчас день, моё состояние: активен
[HumanCatalogAgent-1 · поток 2] искали всех людей: найдено 3
[HumanAgent-1 · поток 3] нашёл: Ольга (учитель), Анна (водитель), Иван (врач)
мир остановлен
```

- **`поток N`** — настоящий `threadId` воркера: агенты действительно работают
  параллельно, а не по очереди в одном потоке.
- **разные `поток`** у разных агентов — прямое следствие распределения по кругу.
- Состояние зависит от реального времени: запусти ночью — все будут `спит`.

## Как изменить опыт

| Что | Как |
|---|---|
| больше/меньше людей | `[humanAgent, 5]` в `Map` |
| другой состав | добавить пару «модуль → количество» |
| больше потоков, чем ядер | `new World(population, { threadPoolSize: 8 })` |
| один поток для сравнения | `new World(population, { threadPoolSize: 1 })` |
| искать конкретного человека | `criteria: { profession: 'врач' }` в сообщении поиска |

Отдельного теста у скрипта нет: вся логика покрыта тестами агентов, которые он
подключает.
