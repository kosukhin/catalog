# `agents/toiletAgent.ts` — туалет

Один туалет на мир: одно место и все желающие, которые идут к нему сами. Человек
занимает место на 20 игровых минут (настройка `minutes`), время считается по часам
мира (`DayAgent`).

Место достаётся не тому, кто спросил первым, а тому, кто **ближе всех подошёл** к
туалету в момент освобождения.

## Что экспортирует

| Экспорт | Назначение |
|---|---|
| `type` | `'ToiletAgent'` |
| `moduleUrl`, `createAgent` | контракт модуля агента |
| `ToiletAgent` | класс |
| `TOILET_AGENT_ID` | `'ToiletAgent-1'` |
| `TOILET_REQUEST`, `TOILET_GRANTED`, `TOILET_QUEUED`, `TOILET_ENTER`, `TOILET_LEAVE`, `TOILET_RELEASED` | типы сообщений |

## Сообщения

| Сообщение | Полезная нагрузка | Что делает туалет |
|---|---|---|
| `toilet-request` | `{ id, replyTo }` | ставит в список желающих и отвечает `toilet-queued`; если место свободно — запускает выбор ближайшего |
| `toilet-queued` | `{ id, position }` | ты в списке желающих на месте `position`: иди к туалету и жди |
| `toilet-granted` | `{ id }` | место твоё, иди |
| `toilet-enter` | `{ id }` | человек дошёл и занял место |
| `toilet-leave` | `{ id }` | человек передумал — убрать из списка желающих |
| `toilet-released` | `{ id }` | 20 игровых минут прошли, место свободно |
| `physics-position` | `{ id, replyTo }` | спрашивает у `PhysicsAgent` позицию желающего |
| `physics-body` | `{ id, body }` | ответ с позицией: по нему считается расстояние до туалета |

## Как работает

1. при старте встаёт в пространство (`physics-register`), чтобы человек мог дойти;
2. `toilet-request`: человек попадает в список желающих и сразу получает `toilet-queued`
   (к туалету он идёт сам); если место свободно и пропуск никому не выдан — начинается выбор;
3. **выбор ближайшего** (`#choose` → `#onPosition` → `#grantNearest`): туалет спрашивает у
   `PhysicsAgent` позиции всех желающих (`physics-position`) и по ответам `physics-body`
   считает расстояние до себя, после чего отдаёт место ближайшему (`toilet-granted`).
   Тот, кто уже внутри или кому пропуск уже выдан, в выборе не участвует;
4. `toilet-enter`: занимает место и спрашивает у `DayAgent` игровое время входа;
5. пока занят, на каждом `tick` спрашивает у часов мира время; когда прошло `minutes`
   игровых минут — шлёт `toilet-released` и снова выбирает ближайшего из желающих.

## Инварианты

- одновременно внутри не больше одного человека;
- пропуск выдаётся только когда внутри никого нет и никто ещё не идёт;
- порядок запросов победителя не решает — решает расстояние до туалета;
- **тот, кто только что вышел, в выборе не участвует**, пока место не получит кто-то
  другой: иначе человек, стоящий у двери, был бы ближе всех и не смог бы уйти (запрет
  «два раза подряд»);
- если желающих нет в пространстве (`physics-body` с `body: null`), место не отдаётся:
  туалет подождёт следующего запроса и попробует снова;
- `describe()` отдаёт минуты, занявшего и длину списка желающих — туалет виден в дашборде.

## Тест

`test/toiletAgent.test.ts` — контракт модуля, регистрация в пространстве, выдача места
после опроса позиций, «ближе всех» побеждает даже тот, кто спросил позже, запрет
«два раза подряд» для только что вышедшего, отказ при отсутствии желающего в
пространстве, освобождение через 20 игровых минут, опрос часов по тику, освобождение
по `toilet-leave`, состояние для дашборда, незнакомое сообщение, проверка настроек.
