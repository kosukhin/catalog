# `agents/toiletAgent.ts` — туалет

Один туалет на мир: одно место и очередь. Человек занимает его на 20 игровых минут
(настройка `minutes`), время считается по часам мира (`DayAgent`).

## Что экспортирует

| Экспорт | Назначение |
|---|---|
| `type` | `'ToiletAgent'` |
| `moduleUrl`, `createAgent` | контракт модуля агента |
| `ToiletAgent` | класс |
| `TOILET_AGENT_ID` | `'ToiletAgent-1'` |
| `TOILET_REQUEST`, `TOILET_GRANTED`, `TOILET_QUEUED`, `TOILET_ENTER`, `TOILET_LEAVE`, `TOILET_RELEASED` | типы сообщений |

## Сообщения

| Сообщение | Полезная нагрузка | Что делает туалет |
|---|---|---|
| `toilet-request` | `{ id, replyTo }` | если свободно — `toilet-granted`, иначе в очередь и `toilet-queued` |
| `toilet-granted` | `{ id }` | место твоё, иди |
| `toilet-queued` | `{ id, position }` | ты в очереди на месте `position` |
| `toilet-enter` | `{ id }` | человек дошёл и занял место |
| `toilet-leave` | `{ id }` | человек ушёл или передумал |
| `toilet-released` | `{ id }` | 20 игровых минут прошли, место свободно |

## Как работает

1. при старте встаёт в пространство (`physics-register`), чтобы человек мог дойти;
2. `toilet-request`: если место свободно и никто ещё не идёт — пускает; иначе ставит в очередь (FIFO);
3. `toilet-enter`: занимает место и спрашивает у `DayAgent` игровое время входа;
4. пока занят, на каждом `tick` спрашивает у часов мира время; когда прошло `minutes`
   игровых минут — шлёт `toilet-released` и пускает следующего из очереди.

## Инварианты

- одновременно внутри не больше одного человека;
- пока место занято или кто-то уже идёт — всех ставят в очередь;
- `describe()` отдаёт минуты, занявшего и длину очереди — туалет виден в дашборде.

## Тест

`test/toiletAgent.test.ts` — контракт модуля, регистрация в пространстве, мимо
первого и очередь для второго, освобождение через 20 игровых минут, опрос часов по
тику, освобождение по `toilet-leave`, состояние для дашборда, незнакомое сообщение,
проверка настроек.
