# `client/physicsView.ts` — чистые помощники отображения

Данные для страницы физики, без three.js: цвет тела по типу, размеры коробки
границ, строки панели. Держится отдельно, чтобы это можно было проверять в Node без
WebGL.

## Что экспортирует

| Экспорт | Назначение |
|---|---|
| `bodyColor(id)` | цвет тела по типу (`HumanAgent`, `ToiletAgent`, `House`, …) |
| `labelOf(id, names)` | текст подписи: имя агента, а без имени — его адрес |
| `isMoving(id, state)` | движется ли тело сейчас |
| `boxOf(bounds)` | `{ size, center }` коробки границ |
| `formatPoint(point)` | строка `x; y; z` |
| `clockLabel(clock)` | время мира: `07:15 · день`, без часов — `время мира: —` |
| `statusLine(тел, движется, clock)` | строка статуса страницы физики |
| `stateRows(state)` | строки `{ label, value }` для панели физики |

Типы (`PhysicsState`, `Bounds`, `Point`, `TimeReport`) берутся из
`agents/physicsAgent.ts` и `agents/dayAgent.ts` — только типами, поэтому в бандл
клиента не попадают.

`clockLabel` печатает **внутримировое** время (`DayAgent` идёт в 10× быстрее
реального), а не время машины: страница физики показывает `07:15 · день`, а не
`14:32:11`. Часы и минуты дополняются нулём, чтобы строка не «прыгала» по ширине.

`statusLine` собирает `тел: 8 · движется: 3 · 07:15 · день`; при отсутствии часов —
`тел: 8 · движется: 3 · время мира: —`.

## Тест

`test/physicsView.test.ts` — цвет по типу, «движется/стоит», размер и центр границ,
формат точки, состав строк панели, подпись времени мира (с ведущим нулём и фазой),
прочерк без часов, строка статуса.
