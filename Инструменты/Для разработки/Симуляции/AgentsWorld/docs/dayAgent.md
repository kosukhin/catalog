# `agents/dayAgent.ts` — время в мире

Модель: [models/DayAgent.md](models/DayAgent.md). Агент отвечает, какое сейчас
число, день недели, время суток (день или ночь). Существует в единственном
экземпляре, поэтому у него постоянный адрес.

## Что экспортирует

| Экспорт | Назначение |
|---|---|
| `type` | `'DayAgent'` — имя для состава мира |
| `moduleUrl` | адрес модуля (поток грузит код по нему) |
| `createAgent` | фабрика для потока |
| `DayAgent` | класс (для прямого использования и тестов) |
| `DAY_AGENT_ID` | `'DayAgent-1'` — адрес, по которому его ищут другие |
| `TIME_REQUEST`, `TIME_REPORT` | типы сообщений |
| `TimeReport`, `DayPhase`, `DayAgentOptions` | типы |

## Как с ним общаются

Как и все акторы — только сообщениями через почтовый ящик:

```js
// любой агент у себя в handle/start:
context.send(DAY_AGENT_ID, createMessage(TIME_REQUEST, { replyTo: context.id }));
// в ответ придёт TIME_REPORT с payload = TimeReport
```

Адрес для ответа передаётся в `payload.replyTo`, потому что контракт актора не
передаёт обработчику отправителя. Если `replyTo` нет — агент не отвечает, но
пишет в лог, что ответить некому (молча терять вопрос нельзя).

## Что в ответе

```js
{
  iso: '2026-11-08T11:30:00.000Z',
  year: 2026, month: 11, monthName: 'ноября',
  dayOfMonth: 8, weekday: 'воскресенье',
  hours: 14, minutes: 30,
  phase: 'день'          // 'день' | 'ночь'
}
```

## Настройки

| Настройка | По умолчанию | Зачем |
|---|---|---|
| `now` | `() => new Date()` | часы агента; подменяются в тестах |
| `timeScale` | 10 | во сколько раз виртуальное время быстрее реального |
| `dayStartHour` | 6 | час, с которого начинается день |
| `nightStartHour` | 22 | час, с которого начинается ночь |

`nightStartHour` обязан быть больше `dayStartHour`, `timeScale` — положительное
конечное число; иначе конструктор бросает исключение.

## Виртуальное время

Агент не читает системные часы напрямую: он считает **виртуальное время**

```
виртуальное = момент_создания + (реальное - момент_создания) * timeScale
```

По умолчанию `timeScale = 10`, то есть сутки в мире проходят за 2.4 реальных часа,
а час — за 6 реальных минут. Точка отсчёта — момент создания агента, поэтому время
идёт плавно: два вопроса подряд покажут разное время.

```js
new DayAgent({ timeScale: 60 });   // реальная минута = виртуальный час
```

`timeScale` виден в `describe()` — дашборд показывает его рядом с часами мира.

## Инварианты

- День — это `dayStartHour <= hours < nightStartHour`; всё остальное — ночь.
- Агент не хранит состояние времени: он считает отчёт в момент вопроса.
- Если экземпляр создан не как `DayAgent-1`, он предупреждает в лог: другие ищут
  его именно по этому адресу.
- На незнакомый тип сообщения отвечает строкой в лог, а не падением.
