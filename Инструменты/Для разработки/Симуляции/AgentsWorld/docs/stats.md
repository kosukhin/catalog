# `src/stats.ts` — статистика мира

Превращает «статистику агентов» в список нарядов и проверяет входные данные.
Ошибка в конфигурации должна всплывать до запуска потоков, а не внутри воркера.

## Что экспортирует

| Имя | Назначение |
|---|---|
| `PopulationStats` | `Record<string, number>` — «тип агента → количество» |
| `normalizePopulation(stats)` | разворачивает статистику в `ActorAssignment[]` |
| `summarizePopulation(assignments)` | обратная сводка: тип → количество |

## Формат статистики

```js
{ EchoAgent: 4, ДругойАгент: 2 }
```

Разворачивается в наряды с предсказуемыми идентификаторами:

```js
[
  { id: 'EchoAgent-1', type: 'EchoAgent', options: {} },
  { id: 'EchoAgent-2', type: 'EchoAgent', options: {} },
  …
]
```

## Инварианты

- Пустой тип (`'  '`) — ошибка.
- Количество должно быть целым неотрицательным: `-1`, `1.5`, `NaN` — ошибка.
- Ноль допустим и означает «агентов этого типа нет».
- Мир не может быть пустым: сумма всех количеств должна быть больше нуля.
- Порядок типов — как в объекте статистики; порядок агентов одного типа — по
  возрастанию индекса. На этом порядке строится распределение по потокам.
