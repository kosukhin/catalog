# `src/world.ts` — мир

Главная абстракция: принимает статистику агентов и запускает их работу.

## Жизненный цикл

```js
const world = new World({ EchoAgent: 4 });
await world.run();   // потоки подняты, агенты работают параллельно
await world.stop();  // агенты остановлены, потоки погашены
```

`run()` ждёт готовности всех потоков и возвращает управление: мир продолжает жить
до `stop()`, блокирующего ожидания нет.

## Что экспортирует

| Имя | Назначение |
|---|---|
| `WorldOptions` | `threadPoolSize`, `registry`, `print` |
| `World` | `actors`, `population`, `running`, `threadCount`, `run`, `stop`, `send` |

## Распределение по потокам

```
workerCount = min(threadPoolSize ?? число ядер, число агентов)
поток агента = индекс агента % workerCount
```

- 4 агента и 4 потока — каждый в своём потоке;
- 6 агентов и 4 потока — 2, 2, 1, 1 (см. `docs/demo.md`);
- агентов больше, чем потоков, — нормально: нагрузка размазывается по кругу;
- потоков больше, чем агентов, — не бывает: лишние потоки не поднимаются.

Распределение по кругу, а не подряд, выбрано специально: соседние по статистике
агенты попадают в разные потоки, и мир не простаивает, пока один поток делает всё.

## Кто знает адреса

`World` — единственное место, где есть карта `id → индекс потока`. Поэтому:

- сообщение между потоками всегда идёт через мир (`deliver` → `send` → нужный поток);
- акторы не знают, где живут остальные, и не могут обратиться к ним напрямую;
- внешний код может послать сообщение в мир через `world.send(from, to, message)`.

## Печать

Строки агентов выводятся через `print` (по умолчанию `console.log`) в формате:

```
[EchoAgent-3 · поток 3] эхо: EchoAgent-3: сообщение 1
```

Номер потока — настоящий `threadId` воркера, поэтому по логу видно параллельность.

## Ошибки

| Ситуация | Поведение |
|---|---|
| некорректная статистика | исключение в конструкторе |
| неизвестный тип агента | исключение в конструкторе (до запуска потоков) |
| повторный `run()` | исключение `мир уже запущен` |
| `stop()` без `run()` | ничего не делает |
| сообщение неизвестному адресату | строка `[мир] нет агента с идентификатором …` |
