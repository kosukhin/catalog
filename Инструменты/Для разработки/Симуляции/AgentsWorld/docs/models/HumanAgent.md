# HumanAgent

Предаставляет одного человека  имеет свойства: имя и пол

## Поведение

Обращается к DayAgent если сейчас ночь то текущее состояние агента - спит. Если день - то активен

Активен - это состояние для дня по умолчанию.

С вероятностью 0.1 - если сейчас день то человек может быть в состоянии в Туалете.

С вероятностью 0.2 - если день то человек может принимать пищу
