# HumanCatalogAgent

Этот агент помогает другим агентам находить друг друга, этот каталог тоже единственный в системе и каждый агент может к нему обратиться для поиска других агентов. Каталог знает об агентах типа HumanAgent, знает об их свойствах и может выполнить поиск по этим свойствам. например по тому кем работает Human или какое у него имя или какой пол.
