# `lib/registry.ts` — реестр агентов

Связывает строковый тип агента с фабрикой, которая создаёт экземпляр.

## Зачем реестр, если есть классы

Статистика мира и наряды для потоков — это данные, и передать в воркер можно только
сериализуемые значения, то есть строки. Поэтому тип агента в системе — строка
(`'EchoAgent'`), а класс ищется по ней в реестре.

Реестр создаётся дважды и независимо:

- в **главном потоке** — чтобы проверить статистику до запуска потоков;
- в **каждом воркере** — чтобы создать акторов из строковых нарядов.

## Что экспортирует

| Имя | Назначение |
|---|---|
| `AgentRegistry` | `register`, `has`, `types`, `create` |
| `createDefaultRegistry()` | реестр со всеми агентами проекта («из коробки» — `EchoAgent`) |

## Инварианты

- Пустой тип и повторная регистрация одного типа — ошибки.
- `create` для неизвестного типа бросает исключение со списком известных типов:
  это и есть сообщение «вы опечатались в статистике».
- Новый агент добавляется в `createDefaultRegistry()` — тогда он доступен и миру,
  и воркерам одновременно.
