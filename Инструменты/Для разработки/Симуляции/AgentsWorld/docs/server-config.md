# `server/config.ts` — конфигурация приложения

Точка сборки мира для сервера: какие агенты подключены и сколько их.

## Что экспортирует

| Имя | Назначение |
|---|---|
| `ServerConfig` | `port`, `humans`, `pageSize`, `clockId`, `population` |
| `createServerConfig(env)` | собирает конфигурацию из окружения |

## Переменные окружения

| Переменная | По умолчанию | Что задаёт |
|---|---|---|
| `PORT` | 3000 | порт HTTP-сервера (`0` — любой свободный, удобно в тестах) |
| `HUMANS` | 12 | сколько людей запустить |
| `PAGE_SIZE` | 20 | размер страницы по умолчанию в `/api/agents` |

Пустая строка считается «не задано». Некорректное значение — исключение с
диапазоном: `PORT должен быть целым числом от 0 до 65535`.

## Состав мира

```js
population = new Map([
    [dayAgent, 1],           // время в мире — единственный
    [humanCatalogAgent, 1],  // каталог людей — единственный
    [humanAgent, humans],    // люди
]);
```

`clockId` — адрес агента, у которого приложение спрашивает виртуальное время
(`DayAgent-1`). Он лежит в конфигурации, чтобы `snapshot.ts` и `app.ts` не знали
про `DayAgent` напрямую.

## Тест

`test/server-config.test.ts` — значения по умолчанию, состав мира, чтение
окружения, пустые переменные, отказ на некорректных значениях.
