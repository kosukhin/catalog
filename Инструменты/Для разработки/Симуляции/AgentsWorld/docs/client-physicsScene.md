# `client/physicsScene.ts` — сцена three.js

Собирает 3D-сцену из состояния физики: рендерер, камера, свет, сетка, wireframe
коробка `bounds`, а на каждое тело — сфера (цвет по типу) и подпись (спрайт с `id`).
Движущиеся тела подсвечиваются и слегка увеличиваются.

Обзор мышью (перетаскивание — поворот, колесо — приближение) реализован здесь же,
без `OrbitControls`, чтобы не тянуть доп. файлы.

## Что экспортирует

| Экспорт | Назначение |
|---|---|
| `createScene(canvas)` | создаёт сцену, возвращает `{ apply(state), dispose() }` |
| `SceneView` | тип контроллера: `apply`, `dispose` |

`apply(state)` каждый кадр подстраивает коробку границ, добавляет/убирает тела,
двигает сферы и подписи и рисует кадр. Тела, которых больше нет в состоянии,
удаляются вместе с геометрией.

## Тест

`test/physicsScene.test.ts` — модуль собирается и экспортирует `createScene`
