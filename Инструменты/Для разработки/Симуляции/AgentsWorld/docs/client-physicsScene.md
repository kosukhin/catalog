# `client/physicsScene.ts` — сцена three.js

Собирает 3D-сцену из состояния физики: рендерер, камера, свет, сетка, wireframe
коробка `bounds`, а на каждое тело — сфера (цвет по типу) и подпись (спрайт с `id`).
Движущиеся тела подсвечиваются и слегка увеличиваются.

Движение тел считает [client-physicsMotion.md](client-physicsMotion.md): `apply(state)`
на каждый опрос только сообщает трекеру новую цель, а кадр берёт у трекера положение
тела на текущее время. Поэтому тела едут линейно, с постоянной скоростью, а не
экспоненциально «догоняют» цель рывками.

Обзор мышью (перетаскивание — поворот, колесо — приближение) реализован здесь же,
без `OrbitControls`, чтобы не тянуть доп. файлы.

## Что экспортирует

| Экспорт | Назначение |
|---|---|
| `createScene(canvas)` | создаёт сцену, возвращает `{ apply(state), dispose() }` |
| `SceneView` | тип контроллера: `apply`, `dispose` |

`apply(state)` подстраивает коробку границ, добавляет/убирает тела и передаёт их
позиции в трекер движения. Тела, которых больше нет в состоянии, удаляются вместе с
геометрией и подписью.

Трекер движения **общий** для тел и объектов, поэтому `prune` вызывается один раз —
по объединению `id` обеих групп. Отдельный `motion.prune(seenObjects)` выбросил бы
из трекера все тела (их нет в наборе объектов), и меши людей замерли бы на месте.
