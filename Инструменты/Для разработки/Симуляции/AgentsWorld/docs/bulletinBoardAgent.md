# `agents/bulletinBoardAgent.ts` — доска объявлений

Помогает агенту найти других агентов по типу. Сам поиск делает реестр мира
(`lib/rosterAgent.ts`): доска спрашивает реестр и пересылает ответ спрашивающему.

## Что экспортирует

| Экспорт | Назначение |
|---|---|
| `type` | `'BulletinBoardAgent'` |
| `moduleUrl`, `createAgent` | контракт модуля агента |
| `BulletinBoardAgent` | класс |
| `BULLETIN_BOARD_AGENT_ID` | `'BulletinBoardAgent-1'` |
| `BULLETIN_FIND`, `BULLETIN_RESULT` | типы сообщений |
| `BulletinResult` | тип данных |

## Сообщения

| Сообщение | Полезная нагрузка | Что делает доска |
|---|---|---|
| `bulletin-find` | `{ type, replyTo }` | спрашивает реестр про тип, ответит `bulletin-result` на `replyTo` |
| `bulletin-result` | `{ type, ids }` | список адресов найденных агентов |

## Как работает

1. приходит `bulletin-find` с типом (например `'BankAgent'`);
2. доска шлёт реестру `roster-query` с этим типом;
3. получив `roster-report`, отвечает `bulletin-result` тому, кто спросил.

Так человек находит банк, а не хранит его адрес жёстко.

## Инварианты

- без `replyTo` поиск не запускается (пишет в лог);
- ответ реестра без запроса — только строка в лог;
- `describe()` отдаёт число активных поисков — доска видна в дашборде.

## Тест

`test/bulletinBoardAgent.test.ts` — контракт модуля, поиск через реестр, ответ
спрашивающему, отказ без `replyTo`, ответ без запроса, состояние для дашборда,
незнакомое сообщение.
