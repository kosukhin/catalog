# `agents/tickAgent.ts` — источник импульсов времени

Агенты в этой системе пассивны: они реагируют на сообщения, но не «тикают» сами.
`TickAgent` — единственный, кто генерирует ход времени: каждые `intervalMs` он
рассылает сообщение `tick` всем адресатам из списка `recipients`.

## Что экспортирует

| Экспорт | Назначение |
|---|---|
| `type` | `'TickAgent'` |
| `moduleUrl`, `createAgent` | контракт модуля агента |
| `TickAgent` | класс |
| `TICK_AGENT_ID` | `'TickAgent-1'` |
| `TickAgentOptions` | `{ intervalMs, recipients }` |

Тип сообщения `tick` живёт в словаре протокола (`lib/protocol.ts`, константа
`TICK`), потому что он общий: слать может любой тикер, реагировать — любой агент.

## Настройки

| Настройка | По умолчанию | Зачем |
|---|---|---|
| `intervalMs` | 1000 | как часто рассылать импульсы |
| `recipients` | `[]` | кого будить: адреса агентов |

Кого будить, решает не тикер, а тот, кто собирает мир: адреса приезжают из
состава мира (`options`):

```js
[agents.tickAgent, { count: 1, options: { intervalMs: 1000, recipients: ['HumanAgent-1'] } }]
```

## Почему отдельный агент, а не таймер внутри каждого

- один таймер на мир вместо N таймеров по потокам;
- частоту меняет одно значение, а не настройки каждого агента;
- агенты остаются простыми: «пришёл `tick` — отреагировал»;
- тикер ничего не знает о получателях — только адреса.

## Инварианты

- Пустой `recipients` — не ошибка: тикер пишет в лог «некого будить» и таймер не
  поднимает.
- `stop()` гасит таймер; повторный вызов безопасен. Без этого таймер жил бы в
  потоке и после остановки мира.
- Несуществующий адресат не ломает тикер: мир напишет в лог
  `нет агента с идентификатором X`, а остальные получат импульс.
- `intervalMs` — целое положительное; иначе исключение при создании.
- `describe()` отдаёт частоту и число адресатов, поэтому тикер виден в дашборде.

## Тест

`test/tickAgent.test.ts` — контракт модуля, значения по умолчанию, рассылка по
таймеру всем адресатам, остановка без «хвостов», пустой список, тип сообщения
`tick`, `describe` для дашборда, незнакомое сообщение, проверка настроек.
