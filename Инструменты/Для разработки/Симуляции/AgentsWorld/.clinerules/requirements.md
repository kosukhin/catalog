# Требования к коду

- Используем TypeScript
- Каждый модуль максимум должен иметь 4 импорта, если импортов больше 4 то разбиваем модуль на несколько подмодулей.
- При выполнении каждой задачи обязательно писать сколько времени осталось на выполнение задачи.
- Не выходить за рамки директории AgentsWorld
- На каждый модуль нужно написать соответствующий ему блок документации в папке docs и соответствующий модульный тест.
- Код должен работать по принципу ActorModel акторы между собой общаться напрямую не должны только через сообщения в почтовые ящики,
- Когда я начинаю фразу со слова объясни, то не нужно ничего менять в коде нужно только дать ответ о котором я спрашиваю
- директория с агентами живет отдельно от кода lib
- В коде комментарии не писать
- Не принимай решений по дизайну сам автоматом, спрашивай у меня
- Если считаешь что нашел баг молча не исправляй, задай мне вопрос баг это или нет
