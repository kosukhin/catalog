# AgentsWorld — контекст и требования к любой задаче

## Что это за проект

Мир агентов (акторов): мир содержит какое-то количество акторов, акторы работают
параллельно через пул потоков, каждый актор выполняет действия по заложенному в него
сценарию. Цель — эмуляция реального параллельного мира.

Папка — учебная песочница внутри репозитория `catalog`
(корень репозитория: `/home/kosukhin/code/catalog`).

## Требования, которые действуют в каждой задаче

1. **Работаем только внутри `AgentsWorld`.** Не менять файлы в других папках
   репозитория (`База`, `Языки`, `SystemDesign`, `Инструменты/...`), если об этом не
   попросили явно.
2. **Минимум лишнего.** Делать ровно то, что просит задача: не рефакторить соседний
   код, не добавлять фичи «на будущее», не переписывать README без просьбы.
3. **Стек фиксирован.** Node.js, ESM (`"type": "module"`), без TypeScript и без
   сборщика. Новые npm-зависимости — только после явного согласования.
4. **Ответ по-русски и коротко.** Сначала план, потом правки, в конце — что именно
   проверено (какие команды запускал и с каким результатом).
5. **Проверяй результат.** Любой код подтверждается запуском: `node --test` или
   `node <файл>`. Без проверки задача не считается сделанной.
6. **Не выдумывай API.** Если поведение библиотеки/платформы неизвестно — проверить
   в документации или запустить минимальный эксперимент.
7. **Никаких заглушек.** В коде не должно оставаться `TODO`, пустых функций и
   «потом допишу» — либо реализация целиком, либо явно обозначенное ограничение.

## Определение готовности задачи

- код запускается и покрыт тестами (`node --test`), тесты зелёные;
- в комментариях и документации объяснено *почему*, а не только *что*;
- в ответе перечислены изменённые файлы и команды проверки.
