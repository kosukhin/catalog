# 📚 Immutable.js — курс

Учебный курс по библиотеке **immutable** (Immutable.js) — постоянные (persistent)
иммутабельные коллекции для JavaScript: `List`, `Map`, `OrderedMap`, `Set`,
`OrderedSet`, `Stack`, `Record`, ленивые `Seq`, `Range`, `Repeat`.

> Версия библиотеки: **immutable 5.2.1** (ноябрь 2026).
> Документация: https://immutable-js.com/docs/v5/
