# 📚 Курс по crocks — точка входа

Курс из двух слоёв: **практика** (как работать с типами) и **теория** (почему эти
типы появились). Практика лежит в корне этой директории, теория — в `Теория/`,
файлы названы одинаково.

> Версия библиотеки: **crocks 0.12.4** (зафиксирована в `package.json`).
> Всё, что написано «проверено», проверяется скриптом `scripts/check-examples.mjs`.

## Как вернуться в контекст после паузы (20–30 минут)

1. Открыть [PROGRESS.md](PROGRESS.md) — там последняя точка и «следующий шаг».
2. Прочитать [ШПАРГАЛКА.md](ШПАРГАЛКА.md) — 5 минут, восстанавливает каркас
   (какие типы есть, какие интерфейсы, чем `map` отличается от `chain`).
3. Прогнать примеры из последнего пройденного урока: `node scripts/check-examples.mjs Урок-3.5-Arrow.md`
   — если всё зелёное, значит память на месте, а не «я всё забыл».
4. Перечитать конец последнего урока: раздел «Резюме урока» + «Чек-лист» —
   чек-лист и есть тест на готовность к следующему уроку.
5. Записать в PROGRESS.md дату и следующий шаг.

## Правила уроков (чтобы примеры не «падали»)

- Каждый блок ```js **самодостаточен**: свои импорты + свои данные.
  Копируется в `.mjs` и запускается как есть.
- Ожидаемые ошибки обёрнуты в `try/catch`, чтобы блок доходил до конца.
- В конце урока: «Резюме» + «Чек-лист перед следующим уроком».
- Проверка: `node scripts/check-examples.mjs` (все уроки) или
  `node scripts/check-examples.mjs Урок-1.1-Maybe.md` (один урок).

## Как запускать примеры

```bash
npm install            # crocks 0.12.4
node скрипт.mjs        # файл с примером из урока
```

```js
import crocks from 'crocks'
const { Maybe, Either, Pair } = crocks

console.log(Maybe.Just(2).map(x => x * 2).toString()) // Just 4
```

> ⚠️ crocks — CommonJS-библиотека без поля `exports`. В ESM-режиме импорт
> отдельного модуля требует полного пути: `import Maybe from 'crocks/Maybe/index.js'`.
> Самый надёжный вариант — default-импорт всей библиотеки (см. урок 0.1).
