# 🧾 Шпаргалка по crocks 0.12

Одна страница, чтобы вернуть каркас за 5 минут. Все факты ниже **прогнаны** на
crocks 0.12.4 — запускай блоки и сверяйся, а не запоминай.

## 1. Запуск

```bash
node файл.mjs        # любой блок из уроков копируется в .mjs и работает
```

```js
import crocks from 'crocks'
const { Maybe, Either, Pair, curry, compose } = crocks

console.log(Maybe.Just(2).map(x => x * 2).toString()) // Just 4
```

- default-импорт — самый надёжный вариант (crocks — CommonJS без `exports`);
- отдельный модуль в ESM только с полным путём: `import Maybe from 'crocks/Maybe/index.js'`;
- имена `arrow`, `arr`, `then`, `runReader`, `runState`, `runTuple`, `pairToTuple`,
  `tupleToPair` и хелпер `maybe` **в 0.12 отсутствуют** (проверено).

## 2. Карта типов: кто что умеет

Прогони — таблица напечатается из самой библиотеки:

```js
import crocks from 'crocks'

const { Maybe, Either, Result, Identity, Pair, Tuple, State, Reader, ReaderT,
        Const, Arrow, Async, Pred, Sum } = crocks

const ifaces = ['isFunctor', 'isApply', 'isApplicative', 'isChain', 'isMonad',
  'isAlt', 'isPlus', 'isSemigroup', 'isMonoid', 'isFoldable', 'isTraversable',
  'isBifunctor', 'isContravariant', 'isProfunctor', 'isSemigroupoid', 'isCategory']

const rows = {
  'Just(1)': Maybe.Just(1),
  'Right(1)': Either.Right(1),
  'Ok(1)': Result.Ok(1),
  'Identity(1)': Identity(1),
  'Pair("l", 1)': Pair('l', 1),
  'Tuple(2)(1,2)': Tuple(2)(1, 2),
  'State.of(1)': State.of(1),
  'Reader.of(1)': Reader.of(1),
  'ReaderT(Maybe).of(1)': ReaderT(Maybe).of(1),
  'Const(Sum)(Sum 1)': Const(Sum)(Sum(1)),
  'Arrow(x=>x)': Arrow(x => x),
  'Async.Resolved(1)': Async.Resolved(1),
  'Pred(x=>x>0)': Pred(x => x > 0),
}

for (const [name, value] of Object.entries(rows)) {
  const on = ifaces.filter(f => crocks[f](value)).map(f => f.slice(2))
  console.log(name.padEnd(22), on.join(', '))
}
```

Что из этого следует:

| Тип | Интерфейсы | Главное |
|---|---|---|
| `Maybe` | Functor, Apply, Applicative, Chain, Monad, Alt, Plus, Semigroup, Traversable | отсутствие значения |
| `Either` / `Result` | то же + Bifunctor (без Plus) | ошибка как значение |
| `Identity` | Functor…Monad, Semigroup, Traversable | контейнер без эффекта |
| `Pair` | Functor, Apply, Chain, Semigroup, Traversable, Bifunctor | **нет `of`** → формально не Applicative, но `ap`/`liftA2` работают |
| `Tuple(n)` | Functor, Semigroup (+ `mapAll`, `project`, `merge`, `toArray`) | арность в типе |
| `State`, `Reader`, `ReaderT` | Functor…Monad | состояние / окружение |
| `Async` | Functor…Monad, Alt, Bifunctor | ленивое асинхронное вычисление |
| `Const(m)` | Functor, Apply, Applicative, Semigroup, Monoid | фантомное значение справа |
| `Arrow` | Semigroupoid, Category, Functor, Contravariant, Profunctor | **не монада** |
| `Pred` | Semigroup, Monoid, Contravariant | **не функтор**: только `contramap` |
| `Sum`/`All`/`Any`/`Max`/`Min`/`First`/`Last`/`Assign`/`Endo` | Semigroup, Monoid | свёртки |

## 3. Методы по задачам

| Задача | Инструмент |
|---|---|
| Завернуть значение | `Maybe.of` / `Just` / `Either.Right` / `Result.Ok` / `Identity` / `Pair` / `State.of` / `Reader.of` / `Async.Resolved` / `Arrow(fn)` |
| Завернуть с проверкой | `safe(pred, x)`, `tryCatch(fn, x)` |
| Преобразовать внутри | `.map(fn)` (ковариантно — выход) |
| Шаг, зависящий от значения | `.chain(x => контейнер)` |
| Применить функцию из контейнера | `.ap(mFn)` — метод; хелпер — **наоборот**: `ap(mVal)(mFn)` |
| Два независимых вычисления | `liftA2(f, a, b)` (нужен `curry`), `liftA3` |
| Запасной путь | `.alt(m)`, `.coalesce(f, g)` |
| Выход | `.option(default)`, `either(l, r)` / `.either(l, r)`, `.merge(fn)`, `.valueOf()`, `.toArray()`, `.runWith(x)`, `.evalWith(s)` / `.execWith(s)`, `.fork(err, ok)` |
| Ошибки | `tryCatch`, `bimap(l, r)`, `bichain(l, r)` |
| Окружение | `Reader(env => ...)`, `Reader.ask()`, `.runWith(env)`, `pipeK` |
| Состояние | `State.get()`, `State.put(s)`, `State.modify(f)` |
| Функция как значение | `Arrow(fn)`, `.map` / `.contramap` / `.promap`, `.compose`, `.first()` / `.second()` / `.both()`, `fanout(f, g)` |
| Свёртка | `foldMap(f, xs)`, `fold(xs)` + монойды |
| Конверсии | `eitherToMaybe`, `maybeToEither`, `eitherToAsync`, `asyncToPromise` |


## 4. Ловушки, на которых спотыкаются

```js
import crocks from 'crocks'
const { Maybe, Either, Pair, Tuple, State, Reader, Const, Sum, foldMap,
        eitherToMaybe, maybeToEither, ap, liftA2, curry, isFunctor } = crocks

// 1. map vs chain: колбэк для map возвращает значение, для chain — контейнер
console.log(Maybe.Just(2).map(x => Maybe.Just(x * 2)).toString())   // Just Just 4
console.log(Maybe.Just(2).chain(x => Maybe.Just(x * 2)).toString()) // Just 4

// 2. Maybe.of(null) — это Just null: of не проверяет, safe проверяет
console.log(Maybe.of(null).toString(), crocks.safe(crocks.isNumber, null).toString())

// 3. Pair.map трогает только ВТОРОЙ компонент, а ap/chain складывают первые
console.log(Pair('log', 1).map(x => x * 10).toString())             // Pair( "log", 10 )
console.log(liftA2(curry((a, b) => a + b), Pair('a', 1), Pair('b', 2)).toString())

// 4. Tuple: map — только последний компонент, mapAll требует N функций
const Two = Tuple(2)
console.log(Two(1, 2).map(x => x * 10).toString())                  // 2-Tuple( 1, 20 )
console.log(Two(1, 2).mapAll(x => x + 1, y => y + '!').toString())  // 2-Tuple( 2, "2!" )
console.log(Two(1, 2).merge((a, b) => a + b))                       // 3

// 5. Either и Maybe не смешиваются — конверсия на границе
console.log(maybeToEither('нет значения', Maybe.Nothing()).toString())
console.log(eitherToMaybe(Either.Left('err')).toString())

// 6. State: runWith → Pair, evalWith → значение, execWith → состояние
const counter = State(s => Pair(s + 1, s * 2))
console.log(counter.runWith(10).toString(), counter.evalWith(10), counter.execWith(10))

// 7. Reader.ap требует Reader, а не окружение
console.log(Reader.of(x => x * 2).ap(Reader.of(21)).runWith({}).toString()) // 42

// 8. Const.of игнорирует аргумент: значение берётся из моноида
console.log(Const(Sum)(Sum(5)).map(x => x * 1000).toString())       // Const(Sum) Sum 5

// 9. foldMap на пустом массиве — TypeError
console.log(foldMap(x => Sum(x), [1, 2, 3]).toString())             // Sum 6

// 10. ap как хелпер читается наоборот: сначала значение, потом функция
console.log(ap(Maybe.of(21))(Maybe.of(x => x * 2)).toString())      // Just 42

// 11. Предикаты интерфейсов — быстрый способ проверить себя
console.log(isFunctor(Pair('l', 1)), isFunctor(crocks.Pred(x => x > 0)))
```

Про `Arrow` и `Async` отдельно:

| Ловушка | Как правильно |
|---|---|
| `.compose` у `Arrow` — это «**затем**», слева направо | `parse.compose(double)` = сначала `parse`, потом `double` |
| `.compose` требует именно `Arrow` | `Arrow.compose: Arrow required` на обычной функции |
| `fanout` — хелпер, а не метод | `fanout(f, g)`; с двумя `Arrow` вернёт `Arrow` |
| `first`/`second`/`both` требуют `Pair` | `Arrow.first: Pair required for inner argument` |
| `Arrow` ленив | ничего не выполняется до `runWith` |
| `Async` ленив | запуск через `.fork(err, ok)` или `.toPromise()`, метода `.run` нет |
