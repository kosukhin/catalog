# Урок 3.4 — `Const`: константный функтор 🔴

> Цель: понять контейнер, который **забывает значение** и сохраняет только
> аккумулятор, и научиться использовать его для свёрток и агрегаций.
> Ключевые слова: `Const(Monoid)`, `valueOf`, `concat`, `ap`, `of`, `foldMap`,
> `fold`.
> Все примеры печатают результат в консоль и проверены на crocks 0.12.
>
> Документация: https://crocks.dev/docs/crocks/Const.html
>
> 📦 **Каждый блок в уроке самодостаточен.** Импорты и определения включены:
> скопируй блок в файл `.mjs` в проекте с `crocks` (`npm install crocks`, если
> его ещё нет) и запусти `node файл.mjs`. Примеры с ожидаемыми ошибками
> обёрнуты в `try/catch`, чтобы блок дорабатывал до конца и печатал сообщение.

## 1. Зачем нужен `Const` и что в нём «const»

Начнём с названия. **Const** — сокращение от *constant functor*: функтор,
который **игнорирует свой аргумент**. Если записать типом:

```text
Const c a  ≡  c
```

Для любого `a` получается один и тот же `c`. Поэтому `map` у `Const` ничего не
меняет — применять функцию просто не к чему:

```js
import crocks from 'crocks'
const { Const, Sum } = crocks

const c = Const(Sum)(Sum(5))

console.log(c.map(x => x * 1000).toString())     // Const(Sum) Sum 5
console.log(c.map(x => 'что угодно').toString()) // Const(Sum) Sum 5
console.log(c.valueOf().toString())              // Sum 5
```

Что бы вы ни передали в `map`, аккумулятор остаётся **постоянным** — отсюда
название. Изменить его может только явный `concat` с другим `Const`.

### Что такое `c` и `a`

`Const c a` — контейнер с двумя параметрами типа:

- `c` — аккумулятор; он **реально хранится** (`Sum 5`);
- `a` — **фантомный** тип результата: в значении его нет.

Один и тот же объект `Const(Sum)(Sum(5))` подходит под типы `Const(Sum) Number`,
`Const(Sum) String` и любой другой `Const(Sum) a`. Параметр `a` нужен только
для типов и обобщённого кода (`traverse`, `foldMap`).

### Почему `Pair` — полезное, но коварное сравнение

`Pair c a` — это `(c, a)`: он хранит **и** контекст, **и** значение. `Const c a`
можно представить как `Pair`, у которого правую часть **стёрли**: остался
только `c`.

```js
import crocks from 'crocks'
const { Pair, Const, Sum } = crocks

const pair = Pair(Sum(5), 42)
const constant = Const(Sum)(Sum(5))

// Pair: значение есть — его можно достать и изменить
console.log(pair.snd())                          // 42
console.log(pair.map(x => x * 2).toString())     // Pair( Sum 5, 84 )

// Const: значения нет — «слот» справа пуст
console.log(constant.toString())                 // Const(Sum) Sum 5
console.log(constant.map(x => x * 2).toString()) // Const(Sum) Sum 5
```

Сравнение с `Pair` помогает увидеть, **чего у `Const` нет** (значения), а не
то, что у него «одно значение». Для наглядности — таблица:

| Тип | Что хранит | `map(f)` |
|---|---|---|
| `Identity a` | только значение `a` | меняет `a` |
| `Pair c a` | контекст `c` **и** значение `a` | меняет `a`, `c` не трогает |
| `Const c a` | только контекст `c` | **ничего не меняет** |

### Зачем это нужно

Представьте, что нужно только накапливать: сумму, максимум, «все ли true»,
первый подходящий элемент. Результат каждого шага не нужен — нужен только
аккумулятор:

```js
import crocks from 'crocks'
const { Sum, foldMap } = crocks

console.log(foldMap(n => Sum(n), [1, 2, 3]).toString()) // Sum 6
```

`foldMap` концептуально заменяет каждый элемент на `Const(Sum)(Sum(n))`,
складывает аккумуляторы через `concat`, а сами `n` выбрасывает. Подробнее — в
разделе 7.

В документации crocks `Const` называют **Delta-функтором**: информация справа
существует в типе, но при наблюдении теряется. Подробнее о названии — урок 0,
подраздел «константный (дельта) функтор».

## 2. Форма: `Const(MonoidTypeRep)(value)`

`Const` — конструктор конструктора, как и `ReaderT`:

```sh
Const :: TypeRep T => T -> Const T
Const c :: c -> Const c a
```

То есть `Const(Sum)` возвращает конструктор, который принимает значение типа
`Sum`:

```js
import crocks from 'crocks'
const { Const, Sum } = crocks

const SumConst = Const(Sum)      // Const(Sum)
const c = SumConst(Sum(5))

console.log(c.toString())      // Const(Sum) Sum 5
console.log(c.valueOf().toString()) // Sum 5 — извлечь аккумулятор
console.log(c.type())          // Const(Sum)
console.log(c['@@type'])       // crocks/Const(Sum)@3
```

⚠️ Конструктор требует **TypeRep** (как `ReaderT`), а значение — **того же
типа**, что и TypeRep. Проверено:

```js
import crocks from 'crocks'
const { Const, Sum } = crocks

const SumConst = Const(Sum)

try {
  Const({})
} catch (e) {
  console.log(e.name + ': ' + e.message)
  // TypeError: Const: TypeRep required for construction
}

try {
  SumConst(5)
} catch (e) {
  console.log(e.name + ': ' + e.message)
  // TypeError: Const(Sum): Sum required
}
```

## 3. Почему `Semigroup` / `Monoid`

`Const` не придумывает собственную операцию сложения. Он **делегирует** её
внутреннему типу-аккумулятору `c` — тому, к которому привязан (`Const(Sum)` →
`Sum`, `Const(Array)` → `Array`). В документации этот тип называют *underlying
type* — «подстилающий», или попросту «внутренний тип».

```js
import crocks from 'crocks'
const { Const, Sum, First, Maybe } = crocks
const { Just } = Maybe

console.log(Const(Sum)(Sum(1)).concat(Const(Sum)(Sum(2))).toString())
// Const(Sum) Sum 3 — сработал Sum.concat

console.log(Const(Array)(['a']).concat(Const(Array)(['b'])).toString())
// Const(Array) [ "a", "b" ] — сработал Array.concat

console.log(Const(String)('ab').concat(Const(String)('cd')).toString())
// Const(String) "abcd" — сработал String.concat

console.log(
  Const(First)(First(Just(1))).concat(Const(First)(First(Just(2)))).toString()
)
// Const(First) First( Just 1 ) — сработал First.concat
```

То есть `Const(Sum)` умеет только «сложить суммы», `Const(Array)` — «склеить
массивы», и ничего больше. Если внутренний тип не умеет `concat`
(`Const(Number)`), `Const` не знает, как складывать, — отсюда ошибка
`Must be fixed to a Semigroup`. Поэтому внутреннему типу нужно быть
**Semigroup** (уметь `concat`), а для `of`/`empty` — **Monoid** (иметь пустой
элемент):

> ⚠️ `Number` — не Semigroup не потому, что числа «нельзя складывать», а потому
> что у числа нет **канонического** `concat`: его можно определить как `+`, `*`,
> `min`, `max`… — вариантов много. Поэтому crocks требует явный враппер:
> `Sum`, `Prod`, `Min`, `Max`. У `String` и `Array` `concat` естественный,
> поэтому они работают напрямую.

| Что требует `Const` | Какие операции доступны |
|---|---|
| Semigroup | `concat`, `ap` |
| Monoid | + `of`, `empty` |

```js
import crocks from 'crocks'
const { Const, Sum, Maybe, isSemigroup, isMonoid } = crocks
const { Just } = Maybe

console.log(isSemigroup(Sum))    // true
console.log(isMonoid(Sum))       // true
console.log(isSemigroup(2))      // false — у числа нет concat
console.log(isSemigroup('ab'))   // true — у строки есть concat
console.log(isSemigroup(Maybe))  // true
console.log(isMonoid(Maybe))     // false — у Maybe нет empty

// Semigroup достаточно для concat/ap:
const MaybeConst = Const(Maybe)
console.log(
  MaybeConst(Just(Sum(1))).concat(MaybeConst(Just(Sum(2)))).valueOf().toString()
)
// Just Sum 3

// но не для of/empty:
try {
  MaybeConst.of()
} catch (e) {
  console.log(e.name + ': ' + e.message)
  // TypeError: Const(Maybe).of: Must be fixed to a Monoid
}
```

> ⚠️ `Const(Number)(2)` **сконструируется** (Number — валидный TypeRep), но
> `concat`, `ap`, `of` и `empty` будут бросать `Must be fixed to a
> Semigroup/Monoid`. Конструирование ≠ наличие операций.

## 4. `map` — проверяет функцию, но не применяет её

У `Const` правая часть фантомная: значения, к которому применился бы `map`,
просто нет. Поэтому `map` **валидирует** аргумент и возвращает **тот же**
`Const`:

```js
import crocks from 'crocks'
const { Const, Sum } = crocks

const c = Const(Array)(['a'])

console.log(c.map(x => x + '!').toString())  // Const(Array) [ "a" ] — функция не применена
console.log(c.toString())                    // Const(Array) [ "a" ] — исходный не изменён
console.log(Const(Sum)(Sum(7)).map(x => x * 100).valueOf().toString()) // Sum 7

try {
  Const(Sum)(Sum(1)).map(null)
} catch (e) {
  console.log(e.name + ': ' + e.message)
  // TypeError: Const(Sum).map: Function required
}
```

Функторные законы при этом выполняются тривиально:

- `c.map(identity) ≡ c`;
- `c.map(compose(f, g)) ≡ c.map(g).map(f)` — обе стороны равны `c`.

Зачем тогда `map`, если он ничего не делает? Чтобы `Const` можно было
использовать в **обобщённом коде**, который ожидает функтор: например, в
`traverse` (раздел 7), где тип вычисления задаётся снаружи. `Const` просто
игнорирует преобразование и продолжает копить аккумулятор.

## 5. `concat` и `ap` — накопление

`concat` объединяет аккумуляторы, а `ap` — это тот же `concat` в
аппликативной одежде. Функция на «функциональной» стороне `Const` не нужна:

```js
import crocks from 'crocks'
const { Const, Sum, curry, liftA2 } = crocks

const SumConst = Const(Sum)

console.log(SumConst(Sum(1)).concat(SumConst(Sum(2))).toString())
// Const(Sum) Sum 3

console.log(Const(Array)(['a']).concat(Const(Array)(['b'])).toString())
// Const(Array) [ "a", "b" ]

console.log(SumConst(Sum(5)).ap(SumConst(Sum(27))).toString())
// Const(Sum) Sum 32 — ap не требует функции

console.log(
  liftA2(curry((a, b) => a + b), SumConst(Sum(1)), SumConst(Sum(2))).toString()
)
// Const(Sum) Sum 3
```

> 📖 `liftA2(add, ...)` **не складывает** значения `Sum` как числа: `add`
> применяется к фантомной правой части, то есть ни к чему. Результат `Sum 3`
> получается только из `concat` двух аккумуляторов. Это ключевое отличие
> `Const` от `Pair`: там `ap` применяет функцию к значению и складывает
> контексты, а здесь значения нет вообще.

## 6. `of` и `empty` — пустой моноид

Если тип — Monoid, у `Const` появляются `of` и `empty`. Оба возвращают
**пустой** элемент моноида:

```js
import crocks from 'crocks'
const { Const, Sum } = crocks

const SumConst = Const(Sum)

console.log(SumConst.of().toString())      // Const(Sum) Sum 0
console.log(SumConst.of(999).toString())   // Const(Sum) Sum 0 — аргумент игнорируется
console.log(SumConst.empty().toString())   // Const(Sum) Sum 0

console.log(Const(String).of().toString()) // Const(String) ""
console.log(Const(Array).of().toString())  // Const(Array) [ ]
```

> ⚠️ **`of(x)` игнорирует `x`.** Это не ошибка: правая часть фантомная, и
> `of` обязан вернуть `Const` с пустым моноидом. Поэтому `Const` нельзя
> использовать как «обычный» `of` для упаковки произвольного значения — для
> этого есть `Maybe.of`, `Either.of` и т. п.

## 7. Связь со свёртками

`foldMap` — это «превратить каждый элемент в Semigroup и сложить их»:

```html
foldMap :: Foldable f, Semigroup s => (a -> s) -> f a -> s
```

```js
import crocks from 'crocks'
const { Sum, Max, All, foldMap } = crocks

console.log(foldMap(x => Sum(x), [1, 2, 3]).toString())                  // Sum 6
console.log(foldMap(s => Sum(s.length), ['12', '34', '567']).toString()) // Sum 7
console.log(foldMap(x => Max(x), [1, 5, 3]).toString())                  // Max 5
console.log(foldMap(x => All(x > 0), [1, 2, 3]).toString())              // All true
console.log(foldMap(s => s.toUpperCase(), ['a', 'b', 'c']))              // 'ABC'
```

`fold` — частный случай, когда элементы уже являются Semigroup:

```js
import crocks from 'crocks'
const { Const, Sum, fold, foldMap } = crocks

console.log(fold([Sum(1), Sum(2), Sum(3)]).toString()) // Sum 6

try {
  foldMap(x => Sum(x), [])
} catch (e) {
  console.log(e.name + ': ' + e.message)
  // TypeError: Array.foldMap: Non-empty Array required
}

console.log(Const(Sum).of().toString()) // Const(Sum) Sum 0 — пустой аккумулятор
```

Почему здесь `Const`? Потому что `foldMap` выражается через `traverse` с
`Const`: каждый элемент «заворачивается» в `Const`, `ap`/`concat` складывают
аккумуляторы, а фантомные значения справа отбрасываются. В crocks `foldMap`
уже есть, но полезно увидеть устройство:

```js
import crocks from 'crocks'
const { Const, Sum, traverse } = crocks

const SumConst = Const(Sum)

const total = traverse(
  SumConst,
  x => SumConst(Sum(x)),
  [1, 2, 3]
)

console.log(total.toString())           // Const(Sum) Sum 6
console.log(total.valueOf().toString()) // Sum 6
```

> ⚠️ `foldMap`/`fold` требуют **непустой** Foldable: на `[]` будет
> `TypeError: Array.foldMap: Non-empty Array required`. Если пустота возможна,
> задавай пустой элемент явно: `Const(Sum).of()`.

## 8. Практика: агрегации и «первый подходящий»

Агрегаты по списку заказов — одна функция `foldMap` на каждый вопрос:

```js
import crocks from 'crocks'
const { Sum, Max, All, Any, foldMap } = crocks

const orders = [
  { id: 1, total: 120, paid: true },
  { id: 2, total: 80, paid: true },
  { id: 3, total: 200, paid: false }
]

console.log(foldMap(o => Sum(o.total), orders).toString())  // Sum 400
console.log(foldMap(o => Max(o.total), orders).toString())  // Max 200
console.log(foldMap(o => All(o.paid), orders).toString())   // All false
console.log(foldMap(o => Any(o.paid), orders).toString())   // Any true
```

«Первый подходящий» через `First` — моноид, который хранит первый непустой
`Just`:

```js
import crocks from 'crocks'
const { First, Maybe, foldMap } = crocks
const { Just, Nothing } = Maybe

const users = [{ name: 'Ivan' }, { name: 'Olga' }, { name: 'Oleg' }]

const firstO = foldMap(
  u => First(u.name.startsWith('O') ? Just(u.name) : Nothing()),
  users
)

console.log(firstO.toString())           // First( Just "Olga" )
console.log(firstO.valueOf().toString()) // Just "Olga"
console.log(firstO.option('нет'))        // 'Olga'

const none = foldMap(
  u => First(u.name.startsWith('X') ? Just(u.name) : Nothing()),
  users
)

console.log(none.toString())    // First( Nothing )
console.log(none.option('нет')) // 'нет'
```

Если аккумулятор нужен в явном виде, `First` заворачивается в `Const`:

```js
import crocks from 'crocks'
const { Const, First } = crocks

const FirstConst = Const(First)

const acc = FirstConst(First('Ivan')).concat(FirstConst(First('Olga')))

console.log(acc.toString())              // Const(First) First( Just "Ivan" )
console.log(acc.valueOf().option('нет')) // 'Ivan'
```

## 9. `Const` vs `Pair` и ограничения

`Pair` (Writer, урок 2.1) и `Const` похожи: оба несут контекст рядом со
значением. Но `Pair` **хранит значение**, а `Const` — только контекст:

```js
import crocks from 'crocks'
const { Pair, Const, Sum } = crocks

console.log(Pair(Sum(1), 10).map(x => x * 2).toString())   // Pair( Sum 1, 20 )
console.log(Const(Sum)(Sum(1)).map(x => x * 2).toString()) // Const(Sum) Sum 1
```

| | `Pair` (2.1) | `Const` |
|---|---|---|
| Что хранит | значение + контекст | только аккумулятор |
| `map` | меняет значение | **ничего не меняет** |
| `chain` | есть (Writer) | **нет** |
| `ap` | применяет функцию + складывает контексты | только складывает |
| Для чего | логи + вычисление | свёртки и агрегации |

Ограничения `Const`:

```js
import crocks from 'crocks'
const { Const, Sum, isApplicative, isMonad } = crocks

const c = Const(Sum)(Sum(1))

console.log(isApplicative(c)) // true
console.log(isMonad(c))       // false
console.log(typeof c.chain)   // 'undefined'
console.log(typeof c.alt)     // 'undefined'

// Const(Number): конструктор есть, накопления нет
const NumConst = Const(Number)
const n = NumConst(2)

console.log(n.toString())                 // Const(Number) 2
console.log(n.map(x => x * 2).toString()) // Const(Number) 2

try {
  n.concat(NumConst(3))
} catch (e) {
  console.log(e.name + ': ' + e.message)
  // TypeError: Const(Number).concat: Must be fixed to a Semigroup
}
```

Коротко:

- `Const` — **не монада**: нет `chain`, нельзя ветвиться по накопленному
   значению;
- `map` — no-op: любое преобразование отбрасывается;
- тип должен быть Semigroup/Monoid, но конструктор это не гарантирует;
- `of(x)` игнорирует `x` и возвращает пустой моноид;
- `foldMap`/`fold` требуют непустой Foldable.

## 10. Резюме урока

| Инструмент | Роль |
|---|---|
| `Const(T)` | конструктор с аккумулятором типа `T` |
| `Const(T)(value)` | значение-аккумулятор |
| `.valueOf()` | извлечь аккумулятор |
| `.map(f)` | проверить `f` и вернуть тот же `Const` |
| `.concat(m)` / `.ap(m)` | сложить аккумуляторы через `concat` |
| `.of()` / `.empty()` | пустой моноид (`of` игнорирует аргумент) |
| `.equals(m)` | сравнить аккумуляторы |
| `foldMap(fn, xs)` | каждый элемент → Semigroup, затем `concat` |
| `fold(xs)` | свернуть готовые Semigroup |
| `traverse(Const(T), fn, xs)` | обобщённая свёртка через `Const` |
