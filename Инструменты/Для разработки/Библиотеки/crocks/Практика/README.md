# 🖥 Практика: задания с проверкой

Слой упражнений к урокам. Каждый урок — отдельная HTML-страница: задания по
разделам урока, проверка ответов прямо в браузере и прогресс, который
сохраняется локально.

> Теория — в [../Теория/](../Теория/README.md), конспекты уроков — в корне курса.
> Практика отвечает на вопрос «получилось ли у меня», а не «что это такое».

## Как открыть

| Способ | Что делать |
|---|---|
| Быстро | двойной клик по `index.html` или по странице урока — работает из файла, сборщик не нужен |
| Через сервер | `npx serve Практика` (или любой статик-сервер), если браузер строго относится к `file://` |
| Проверки кода | один раз выполнить `npm install` в корне курса: подхватится локальная сборка `node_modules/crocks/dist/crocks.min.js` |

Если локальной сборки нет, страница попробует взять `crocks@0.12.4` с unpkg.
Без библиотеки (нет `node_modules` и нет интернета) задания «вывод» и «выбор»
продолжают работать, задания «код» честно сообщают, что песочница недоступна.

## Типы заданий

| Тип | Что делает ученик | Как проверяется |
|---|---|---|
| `input` | вводит вывод `console.log` | нормализованное сравнение с `expected` (регистр, пробелы, кавычки и `ё`/`е` не важны) |
| `choice` | выбирает один вариант | сравнение id с `answer` |
| `code` | пишет одно выражение | выполняется на настоящем `crocks` в браузере, результат сравнивается с `target.value` |
| `matrix` | заполняет таблицу «значение → интерфейс» | построчное сравнение с `row.answer` |

Обратная связь не ограничивается «верно/неверно»: в каждом задании есть
подсказка, объяснение (`why`) и кнопка «Показать ответ».

> 💡 **Подсказка наводит, а не отвечает.** `hint` — это вопрос или напоминание
> правила, `placeholder` — формат ввода, а не готовое выражение. Скрипт
> проверки падает, если `hint` или `placeholder` содержит эталон
> (`checkNoLeak`), так что «утечку» ответа не пропустит ревью.

## Структура

```
Практика/
├── index.html                     # список уроков и статусов
├── Урок-0-Термины-ФП.html         # страница практики к уроку 0
└── assets/
    ├── practice.css               # общий стиль всех страниц
    ├── practice.js                # движок: рендер, проверка, прогресс
    └── lesson-0.js               # данные заданий урока 0
```

Данные заданий отделены от движка: страница урока — это разметка шапки и два
`<script>`; всё остальное собирается из `lesson-N.js`.

## Как добавить урок

1. Скопировать `Урок-0-Термины-ФП.html` в `Урок-<номер>-<тема>.html`, поменять
   заголовки, `title`, подпись в шапке и подключить `assets/lesson-N.js`.
2. Создать `assets/lesson-N.js` по образцу `lesson-0.js`: массив `tasks` +
   объект `lesson` с секциями (id секций должны совпадать с `section` заданий)
   и вызовом `Practice.lesson(lesson)`.
3. Добавить строку в таблицу уроков на `index.html`.
4. Проверить ожидания: `npm run check:practice`.

## Проверка ожидаемых ответов

```bash
npm run check:practice     # node scripts/check-practice.mjs
```

Скрипт прогоняет каждый файл `assets/lesson-*.js` на реальном `crocks 0.12.4` и
сверяет:

- `input` — что `setup + expr` действительно печатает `expected`;
- `code` — что эталонное решение даёт ожидаемый `toString`;
- `matrix` — что уровень интерфейса вычислен по предикатам верно;
- `choice` — что правильный id есть среди вариантов.

Так ожидания в заданиях не расходятся с поведением библиотеки: если в `expr`
опечатка, это увидит скрипт, а не ученик.

## Мелочи, о которых стоит знать

- Задания и проверки собираются скриптом, поэтому нужен JavaScript; без него
  страница показывает предупреждение.
- Прогресс хранится в `localStorage` под ключом `crocks-practice-v1:<id урока>`.
  Кнопка «Сбросить» очищает его (нужно нажать дважды — защита от случайности).
- Задания «код» выполняются как **одно выражение** (`Just(8).chain(half)`);
  многострочные инструкции с `return` не поддерживаются намеренно — так
  задание остаётся про операцию, а не про синтаксис.
- Песочница — ваш собственный браузер и ваша же страница: это учебная
  проверка, а не граница безопасности.
