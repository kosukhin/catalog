практика

Задания с проверкой по урокам

Каждая страница — набор заданий к одному уроку: предсказать вывод консоли, выбрать операцию, написать выражение. Ответы проверяются в браузере на настоящем crocks 0.12.4, прогресс сохраняется локально.

Первый запуск. Задания «что напечатает код» и «выбор» работают сразу. Для заданий «напиши код» нужна библиотека: выполни npm install в корне курса (тогда подхватится локальная сборка node_modules/crocks/dist/crocks.min.js) — либо открой страницу с доступом в интернет, сработает запасной CDN.

Как устроено

  • Данные заданий лежит в assets/lesson-N.js, движок — в assets/practice.js, стиль — в assets/practice.css.
  • Ожидаемые ответы сверены с реальным выводом crocks 0.12.4 скриптом scripts/check-practice.mjs (запуск: npm run check:practice).
  • Прогресс хранится в localStorage по ключу crocks-practice-v1:<урок>, кнопка «Сбросить» его очищает.

Правила курса и порядок уроков — в PLAN.md, точка возврата после паузы — в PROGRESS.md.
