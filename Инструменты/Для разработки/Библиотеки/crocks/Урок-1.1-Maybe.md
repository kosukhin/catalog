# Урок 1.1 — `Maybe`: обработка отсутствия значения 🟢

> Цель: научиться заменять `null`/`undefined`-проверки и `if/else` на декларативные
> цепочки с `Maybe`. Ключевые слова урока: `Just` / `Nothing`, `safe`, `option`,
> `either`, `alt`, `coalesce`, `chain`.
>
> Документация: https://crocks.dev/docs/crocks/Maybe.html

## 1. Зачем нужен Maybe

`Maybe` — контейнер, который кодирует контекст «**значение может отсутствовать**».
У него ровно два варианта:

- `Maybe.Just(x)` — значение есть (успех);
- `Maybe.Nothing()` — значения нет (без ошибки, «пусто»).

Проблема обычного JS:

```js
function getCity(user) {
  if (user && user.address && user.address.city) {
    return user.address.city
  }
  return 'не указан' // вызывающий код обязан помнить об этом
}
```

Каждое обращение к вложенному полю — потенциальный `TypeError: Cannot read
property ... of undefined`. С `Maybe` мы делаем отсутствие значения **явной частью
типа результата**, и вся проверка переносится внутрь контейнера:

```js
import crocks from 'crocks'
const { Maybe, getPath } = crocks

const getCity = getPath(['address', 'city']) // (obj) -> Maybe city

getCity({ address: { city: 'Москва' } }) // Just 'Москва'
getCity({ address: {} })                 // Nothing — без ошибок!
getCity(null)                            // Nothing — даже null безопасен
```

## 2. Создание Maybe

```js
import crocks from 'crocks'
const { Maybe } = crocks

// вручную
const a = Maybe.Just(42)      // Just 42
const b = Maybe.Nothing()     // Nothing

// Maybe.of — обёртка любого значения (обязательно, не nullable!)
Maybe.of(1)      // Just 1
Maybe.of(null)   // Just null ← ловушка! of НЕ превращает null в Nothing
```

> ⚠️ `Maybe.of(null)` даёт `Just null`. Контейнер не «угадывает», отсутствует ли
> значение. Поэтому в crocks есть конструкторы-проверки из следующего раздела.

### `safe` — самый частый способ создания

`safe` оборачивает предикат в функцию, которая возвращает `Just` при выполнении
предиката и `Nothing` иначе:

```js
import crocks from 'crocks'
const { safe, Maybe } = crocks

// (предикат) -> (значение) -> Maybe значение
const toNumber = safe(x => typeof x === 'number')

toNumber(5)      // Just 5
toNumber('5')    // Nothing
toNumber(null)   // Nothing
```

## 3. `map` — преобразование значения внутри контейнера

```js
import crocks from 'crocks'
const { Maybe } = crocks

Maybe.Just(21).map(x => x * 2) // Just 42
Maybe.Nothing().map(x => x * 2) // Nothing — функция просто не вызывается

// Гарантия: если результат map — null/undefined, crocks «схлопывает» его в Nothing
Maybe.Just(null).map(x => x) // Nothing

## 4. `chain` — соединение шагов, каждый из которых может «отсутствовать»

`map` не подходит, когда сама функция уже возвращает Maybe (иначе получится
`Just (Just x)` — двойная обёртка). Для этого есть `chain`: он берёт функцию
`x -> Maybe b` и «схлопывает» вложенность:

```js
import crocks from 'crocks'
const { Maybe, safe, pipe, chain, getPath, prop } = crocks

const isEmail = safe(s => s.includes('@'))

// chain: функция возвращает Maybe, результат остаётся одинарной обёрткой
getPath(['user', 'email'])({ user: { email: 'ivan@mail.ru' } })
  .chain(isEmail)
// Just 'ivan@mail.ru'

getPath(['user', 'email'])({ user: { email: 'не-email' } })
  .chain(isEmail)
// Nothing (предикат не прошёл)
```

Правило выбора:
- шаг возвращает **обычное значение** → `map`;
- шаг возвращает **Maybe** → `chain`.

## 5. `option` и `either` — разворачивание контейнера

`option` подставляет дефолт вместо `Nothing`:

```js
import crocks from 'crocks'
const { Maybe, getPath } = crocks

getPath(['address', 'city'])({ address: { city: 'Москва' } })
  .option('не указан') // 'Москва'

getPath(['address', 'city'])({})
  .option('не указан') // 'не указан'
```

`either` — точка, где Maybe «взрывается» обратно в обычный код. Получает две
функции: для `Nothing` и для `Just`:

```js
import crocks from 'crocks'
const { Maybe, getPath, either } = crocks

const render = either(
  () => 'город не указан',       // ветка Nothing
  city => `город: ${city}`       // ветка Just
)

render(getPath(['address', 'city'])({ address: { city: 'Москва' } })) // 'город: Москва'
render(getPath(['address', 'city'])({}))                              // 'город не указан'
```

> Отличие: `option` подставляет одно **значение**, `either` выбирает между двумя
> **функциями** (можно логировать, форматировать, менять тип результата).

## 6. `alt` и `coalesce` — запасное значение внутри цепочки

`alt` (pointfree или метод) заменяет `Nothing` другим Maybe:

```js
import crocks from 'crocks'
const { Maybe, getPath, alt } = crocks

const getCity = o =>
  getPath(['address', 'city'])(o)
    .alt(Maybe.Just('город не указан')) // Nothing -> Just 'город не указан'
    .option()

getCity({ address: { city: 'Москва' } }) // 'Москва'
getCity({})                              // 'город не указан'
```

`coalesce` — то же, но принимает две функции: для Nothing и для Just
(у метода — оба аргумента в одном вызове):

```js
import crocks from 'crocks'
const { Maybe } = crocks

// метод: coalesce(fNothing, fJust)
Maybe.Nothing().coalesce(() => 0, x => x).option()       // 0
Maybe.Just(21).coalesce(() => 0, x => x * 2).option()    // 42
```

Разница с `alt`: `alt` ожидает готовый Maybe (лениво строить сложное значение не
получится), `coalesce` — функции, поэтому «дорогой» дефолт вычисляется только
при необходимости.

## 7. Замена `if/else` и null-проверок: полный пример

```js
import crocks from 'crocks'
const { Maybe, safe, prop, getPath, pipe, chain, option } = crocks

const user = {
  profile: { age: 30, email: 'ivan@mail.ru' },
  settings: { theme: 'dark' },
}

const isNumber = safe(x => typeof x === 'number')
const isPositive = x => x > 0 ? Maybe.Just(x) : Maybe.Nothing()

// императивный оригинал
function getAgeOld(u) {
  const age = u?.profile?.age
  if (typeof age !== 'number') return null
  if (age <= 0) return null
  return Math.floor(age)
}

// версия с Maybe
const getAge = pipe(
  getPath(['profile', 'age']), // Just age | Nothing
  chain(isNumber),             // проверка типа
  chain(isPositive),           // проверка значения
  chain(x => Maybe.of(Math.floor(x)))
)

getAge(user)           // Just 30
getAge({})             // Nothing — нет поля
getAge({ profile: { age: -5 } }) // Nothing — отрицательный возраст

// и точка входа в «нормальный» мир:
getAge(user).option(0) // 30
```

Обрати внимание: `prop` и `getPath` — уже Maybe-безопасные производители:
`prop('profile')(user)` даёт `Just {...}` или `Nothing`, так что их можно
просто соединять через `chain` без всяких `safe`.

## 8. Когда Maybe — не лучший выбор

`Nothing` не несёт информации о **причине**. Если нужно сообщить, почему значения
нет (код ошибки, текст), используй `Either` / `Result` — урок 1.2.

Также заметь: хелпер `maybe` из документации crocks в версии 0.12 отсутствует —
его роль выполняют `option`, `coalesce` и `either`.

## 9. Резюме урока

| Инструмент | Сигнатура / роль |
|---|---|
| `Maybe.Just(x)` / `Maybe.Nothing()` | создать контейнер «есть» / «нет» |
| `Maybe.of(x)` | обёртка значения (null превращает в `Just null` — осторожно!) |
| `safe(предикат)` | `(a) -> Maybe a` в зависимости от предиката |
| `map(f)` | преобразовать Just-значение, Nothing пропускает |
| `chain(f: a -> Maybe b)` | соединить шаги, каждый из которых может отсутствовать |
| `option(дефолт)` | развернуть: значение или дефолт |
| `either(fNothing, fJust)` | развернуть в две ветки кода |
| `alt(другойMaybe)` | запасной Maybe вместо Nothing |
| `coalesce(fNothing, fJust)` | две функции вместо Nothing/Just |
| `prop`, `getPath`, `find` | готовые Maybe-производители из crocks |
