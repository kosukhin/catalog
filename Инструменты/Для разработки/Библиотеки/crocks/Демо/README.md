# 🎬 Демо: визуализации концепций уроков

Третий слой курса. Конспект отвечает «что это за термин», практика — «получилось
ли у меня», а **демо — «как это работает внутри»**: где коробка контейнера, куда
смотрит стрелка функции, откуда берутся две ошибки, почему шаг не вызвался.

> **Тема демо — светлая**, в отличие от тёмных конспектов и практики: схемы из
> коробок и стрелок лучше читаются на «бумажном» фоне, а печать выглядит как экран.
> Вся палитра собрана в `assets/demo.css` (`:root`), файл самодостаточный — страницы
> подключают только его. Сцены — в `assets/scenes-N.js`, движок — `assets/demo.js`.

## Как открыть

| Способ | Что делать |
|---|---|
| Быстро | двойной клик по `index.html` или по странице урока — работает из файла |
| Через сервер | `npx serve Демо`, если браузер строго относится к `file://` |
| Значения | один раз `npm install` в корне курса — подхватятся `node_modules/crocks/dist/crocks.min.js` и `node_modules/three/build/three.min.js`; без них страница пробует CDN |

Страница без библиотеки не ломается: визуализации рисуются, а вместо значений
появляется предупреждение — это честнее, чем показывать выдуманные числа.

## Сцены к уроку 0

| № | Сцена | Что показывает | Что покрутить |
|---|---|---|---|
| 1 | `of` — конвейер упаковки | значение въезжает в коробку, форма контекста не меняется | значение и контейнер (`Maybe`/`Either`/`Result`); поймай `Just null` |
| 2 | `map` — функция внутри коробки | функция применяется к значению, а `Nothing`/`Left` остаются собой | контейнер и `map`/`chain` для функции с контейнером |
| 3 | Законы: две записи одного и того же | обе дорожки дают один результат (`equals` → `true`) | уровень (функтор/аппликатив/монада) и значение |
| 4 | Аппликатив: независимые коробки | две проверки независимы; `Result` копит ошибки, `Either` — нет | валидность полей и движок ошибок |
| 5 | Монада: `chain` сплющивает слой | конвейер шагов; сбой отменяет следующие шаги | число (чётное/нечётное) и `map` против `chain` |
| 6 | Иерархия интерфейсов и предикаты | функтор ⊂ аппликатив ⊂ монада; предикаты по цепочке | тип: `Maybe`, `Either`, `Pair`, `Tuple`, `Pred`, `Sum`, `Const` |
| 7 | Вариативность: `map`/`contramap`/`promap` | направление функции: выход, вход, оба конца | интерфейс и входную строку |
| 8 | Три операции на одной форме | `map` приводит значение, `liftA2` комбинирует, `chain` тянет зависимый шаг | имя (`'  Ivan  '`, пусто, `Petr`) и возраст |

Всего 8 сцен. Сколько получилось положений контролов и эталонов — печатает сам
скрипт проверки: сейчас это 70 состояний и 326 шагов, и все они сверены
с библиотекой (`npm run check:demo`).

## 3D-сцена: доставка дроном (отдельно от уроков)

[Доставка-дроном.html](Доставка-дроном.html) — реальная система, а не абстракция:
служба доставки принимает заявку и решает, полетит дрон или нет.

| Что покрутить | Что решает crocks |
|---|---|
| адрес «Лесная 7» / «Порт 12» | `Maybe`: адрес есть в базе площадок → `Just "P-07"`, иначе `Nothing` |
| вес 0.8 … 3.4 кг | `Either`: перегруз (лимит 2.4 кг) |
| ветер 0 / 6 / 12 м/с | `Either`: сильный ветер (лимит 9 м/с) |
| заряд 100 / 55 / 30 % | `Either`: не хватает на рейс с резервом 15 % |
| скорость показа | как быстро проигрывается рейс |

`Reader` считает расход заряда под условия: одна функция, а окружение
(ветер, вес, дистанция) подставляется. `State` ведёт сам полёт: фазы,
координаты, заряд. Пока рейс разрешён, груз — `Maybe.Just` на борту;
после сброса он становится `Nothing`, а на площадке клиента появляется посылка.
Отказ — не авария, а нормальный `Left` с причиной: дрон остаётся на базе,
кольцо площадки краснеет, над ней горит «ВЫЛЕТ ОТМЕНЁН».

Файлы:

- `assets/drone-model.js` — вся семантика без DOM и three.js:
  `build(state, crocks)` (решение + лента шагов) и `frameAt(model, crocks, t)`
  (кадр: фаза, координаты, заряд, груз как `Maybe`, доставка);
- `assets/drone-stage.js` — three.js: город, площадки, дрон с винтами, груз,
  ветер, маршрут. Читает кадр и переводит его в меши и цвета.

Проверка: `npm run check:drone` — все комбинации контролов, сверка живого
вывода crocks с эталоном и инварианты кадров (заряд только падает и в конце
равен «стартовый − расход», отказавший рейс остаётся на базе и не теряет груз,
успешный — сбрасывает его и садится).

Параметры адреса — открыть сцену в нужном состоянии:

```
Доставка-дроном.html?payload=3.4&wind=6&battery=55&address=Лесная 7&t=0.5
```

`t` (0…1) останавливает рейс на моменте — удобно показать отказ или посадку.

> **Про версию three.js.** Взят **0.149.0** — последняя версия с UMD-сборкой
> `build/three.min.js`. Более новые поставляются только как ES-модули, и тогда
> странице был бы нужен сервер и importmap вместо двойного клика по файлу.
> Поэтому страница грузит `node_modules/three/build/three.min.js`, а при его
> отсутствии — CDN.

## Как устроена сцена

Сцена — это данные, а не разметка: контролы + две функции.

```js
var sceneOf = {
  id: 'of',
  kicker: 'сцена 1 · раздел 1',
  title: '`of` — конвейер упаковки',
  idea: '...',                 // 1–2 строки: что видно на сцене
  hint: '...',                 // сноска под сценой
  stageCaption: '...',         // подпись над визуализацией
  controls: [
    { id: 'box', label: 'контейнер', type: 'select', value: 'Maybe',
      options: [{ value: 'Maybe', label: 'Maybe' }] }
  ],

  // 1) что посчитать: живой crocks + статический эталон expect
  run: function (state, crocks) {
    var value = crocks.Maybe.of(42)
    return {
      view: { value: value.toString() },
      steps: [
        { code: 'Maybe.of(42)', value: value.toString(), expect: 'Just 42' }
      ]
    }
  },

  // 2) как нарисовать: только из view + kit
  draw: function (view, stage, k) {
    stage.appendChild(k.flow([
      k.box({ label: 'значение', value: '42' }),
      k.arrow('of'),
      k.box({ label: 'Maybe', value: view.value, tone: 'ok' })
    ]))
  }
}
```

Типы контролов: `select` (список), `chips` (кнопки-переключатели, 2–7 вариантов),
`range` (ползунок, нужен `samples` для проверки), `text` (нужен `samples`).

Из `kit` доступны: `el`, `md`, `elHtml`, `clear`, `box`, `arrow`, `flow`, `stack`,
`note`, `caption`. Стрелка назад — `k.arrow('contramap', true)`.

## Как добавить урок

1. Скопировать `Урок-0-Термины-ФП.html` в `Урок-<номер>-<тема>.html`, поменять
   заголовки и подключить `assets/scenes-<номер>.js`.
2. Создать `assets/scenes-<номер>.js` по образцу `scenes-0.js`: сцены + в конце
   `root.DEMO_SCENES_<номер> = lesson; if (root.Demo) root.Demo.page(lesson)`.
3. Добавить строку в таблицу уроков на `index.html`.
4. Прогнать `npm run check:demo` — эталоны должны сойтись.

## Проверка эталонов

```bash
npm run check:demo      # два шага: значения, затем отрисовка
```

**Шаг 1 — значения** (`scripts/check-demo.mjs`): берёт каждый
`assets/scenes-*.js`, перебирает **все** комбинации контролов
(`select`/`chips` — все варианты, `range`/`text` — `samples`) и для каждого шага
сравнивает живой вывод crocks с полем `expect`. Он же проверяет структуру: id
сцен уникальны, у контролов есть `options`/`samples`, `run` возвращает `view`
и шаги.

**Шаг 2 — отрисовка** (`scripts/check-demo-render.mjs`): поднимает минимальный
DOM-стаб, собирает страницу так же, как браузер, проверяет, что у каждой сцены
есть контролы, сцена и лента без ⚠, и дёргает каждый контрол — так ловятся
ошибки в `draw()` и обработчиках, которые иначе видны только глазами.

**Отдельно — 3D-сцена:**

```bash
npm run check:drone     # модель и кадры, без браузера и без WebGL
```

`scripts/check-drone.mjs` загружает `assets/drone-model.js` так же, как это
сделает страница, перебирает все комбинации контролов и сверяет каждый шаг
ленты (`Maybe` адреса, `Reader` расхода, проверки `Either`, вердикт) с эталоном.
Дальше он проверяет не «картинку», а инварианты кадров: заряд только падает
и в конце равен «стартовый − расход»; дрон не уходит под землю и не выезжает
за маршрут; отказавший рейс стоит на базе и не теряет груз; успешный —
сбрасывает посылку (`Maybe` → `Nothing`) и садится обратно. WebGL для такой
проверки не нужен: сцена — это данные.

> 💡 **Почему эталон статический.** Если бы `expect` вычислялся тем же кодом, что
> и `value`, проверка была бы бессмысленной. Эталон написан руками (в том числе
> руками описаны ожидаемые строки ошибок), поэтому расхождение видно и в браузере
> (значок ⚠ в ленте), и в скрипте.

## Мелочи, о которых стоит знать

- Значения в ленте печатаются как `toString()` crocks: `Just 42`, `Left "err"`,
  `Pair( "log", 50 )`, `Ok { name: "Ivan", age: 21 }`.
- Сцены считают на **настоящей** библиотеке в вашем браузере — это учебная
  иллюстрация, а не песочница безопасности.
- Порядок сцен повторяет разделы урока, чтобы демо можно было открыть рядом
  с конспектом.
