# Урок 2.2 — `Tuple`: типизированная пара из N элементов 🟡

> Цель: освоить «Pair с N компонентами и жёсткой арностью» — контейнер-запись
> без имён полей: создать, читать (`project`), преобразовывать (`map`/`mapAll`/
> `nmap`) и разворачивать (`merge`, `tupleToArray`). Понять, когда Tuple, а
> когда Pair. Ключевые слова: `Tuple(n)`, `project`, `mapAll`, `nmap`.
> Все примеры печатают результат в консоль и проверены на crocks 0.12.
>
> Документация: https://crocks.dev/docs/crocks/Tuple.html

## 1. Зачем нужен Tuple

`Pair` — всегда ровно два компонента. `Tuple` — **фиксированная запись из N
компонентов** (1–10 и больше), у которой главное свойство — **жёсткая
арность**: создать «3-кортеж из двух значений» просто нельзя, crocks кинет
ошибку. Типичные роли:

- «значение + несколько сопровождающих полей»: результат + счётчик + флаг;
- компактная запись без имён полей: координаты, RGB-цвет, диапазон;
- возврат **нескольких значений из функции с гарантией**: получатель точно
   знает, что элементов ровно N, — не как с массивом.

Отличие от Pair по духу: Pair — «значение + контекст» (контекст накапливается
через `chain`/`ap`, см. Writer в уроке 2.1), Tuple — «ровно N полей, просто
данные». У Tuple поэтому **нет** `chain`/`ap`/`bimap` — он не про эффекты.

---

## 2. Создание

Конструктор двухступенчатый: сначала `Tuple(n)` — «фиксируем арность», потом
вызов с N аргументами:

```js
import crocks from 'crocks'
const { Tuple } = crocks

const Triple = Tuple(3)           // конструктор 3-кортежей
const t = Triple(1, 'a', true)

console.log(t.toString())          // 3-Tuple( 1, "a", true )
console.log(t.tupleLength())       // 3
console.log(t.toArray())           // [ 1, 'a', true ]
console.log(Triple(1, 'a', true).equals(Triple(1, 'a', true))) // true

// жёсткая арность:
// Triple(1, 2) — TypeError: 3-Tuple: Expected 3 values, but got 2
```

Каждая арность — свой тип: `3-Tuple` и `2-Tuple` не равны и не взаимозаменяемы
(сравни через `equals` — только с кортежем той же длины).

---

## 3. Доступ: `project` — и внимание, индексация с ЕДИНИЦЫ

```js
import crocks from 'crocks'
const { Tuple, project } = crocks

const Triple = Tuple(3)
const t = Triple(1, 'a', true)

console.log(t.project(1)) // 1
console.log(t.project(2)) // 'a'

// pointfree-версия
console.log(project(3)(t)) // true
```

> ⚠️ **Индексы начинаются с 1** (как в математике), а не с 0 (как в массивах)!
> `t.project(0)` и `t.project(4)` → `TypeError: Index should be an integer
> between 1 and 3` (проверено). Привычка к массивам — главный источник ошибок тут.

---

## 4. `map`, `mapAll`, `nmap` — преобразования

`map`, как у Pair (урок 2.1), применяет функцию **только к последнему
компоненту**:

```js
import crocks from 'crocks'
const { Tuple } = crocks

const Triple = Tuple(3)

console.log(Triple(1, 2, 3).map(x => x * 10).toString())
// 3-Tuple( 1, 2, 30 ) — только последний
```

Чтобы преобразовать **все** компоненты — `mapAll` с N функциями:

```js
import crocks from 'crocks'
const { Tuple, nmap } = crocks

const Triple = Tuple(3)
const t = Triple(1, 'a', true)

console.log(t.mapAll(x => x + 1, y => y + '!', z => !z).toString())
// 3-Tuple( 2, "a!", false )

// pointfree-версия mapAll — nmap: nmap(N)(f1, ..., fN)(tuple)
console.log(nmap(3)(x => x + 1, y => y + '!', z => !z)(t).toString())
// 3-Tuple( 2, "a!", false )
```

> ⚠️ `nmap` проверяет арность: `nmap(2)(f1, f2)(какой-нибудь 3-Tuple)` →
> `TypeError: nmap: 2-Tuple required`. Число функций обязано совпадать с длиной.

## 5. `merge` — разворачивание в обычный код

Точка выхода из Tuple-мира — `merge` с N-арной функцией (аналог `merge` у Pair
из урока 2.1 и `option`/`either` из уроков 1.1–1.2):

```js
import crocks from 'crocks'
const { Tuple } = crocks

const Triple = Tuple(3)
const Pair2 = Tuple(2)

console.log(Triple(1, 2, 3).merge((a, b, c) => a + b + c)) // 6
console.log(Pair2('Ivan', 30).merge((name, age) => `${name} (${age})`))
// 'Ivan (30)'
```

> ⚠️ В плане урока было слово `runTuple` — в crocks 0.12 такого метода/функции
> **нет** (проверено): его роль играет `merge`. Встретишь `runTuple` в старых
> статьях — это про `merge`.

## 6. `concat` — поэлементное сложение

Как у Pair: если **все** компоненты обоих кортежей — полугруппы (массивы,
строки, моноиды урока 5.x), складываем поэлементно:

```js
import crocks from 'crocks'
const { Tuple } = crocks

const Pair2 = Tuple(2)

console.log(Pair2([1], 'a').concat(Pair2([2], 'b')).toString())
// 2-Tuple( [ 1, 2 ], "ab" ) — первые с первыми, вторые со вторыми
```

---

## 7. `tupleToArray` — мост в мир массивов

Две формы (обе полезны):

```js
import crocks from 'crocks'
const { Tuple, tupleToArray } = crocks

const Triple = Tuple(3)
const t = Triple(1, 'a', true)

// 1) Tuple -> массив
console.log(tupleToArray(t)) // [ 1, 'a', true ]

// 2) «функция, возвращающая Tuple» -> «функция, возвращающая массив»
const makeTriple = x => Triple(x, x * 2, x * 3)
const makeArray = tupleToArray(makeTriple)
console.log(makeArray(5)) // [ 5, 10, 15 ] — удобно для API, ждущих массивы
```

Вторая форма — маленький, но приятный паттерн: пишешь функцию со
строгой N-арной гарантией, а наружу отдаёшь обычный массив.

## 8. Tuple vs Pair: как выбирать

| | `Pair` (урок 2.1) | `Tuple` |
|---|---|---|
| Компонентов | ровно 2 | N (фиксируется при создании) |
| Дух | «значение + контекст» | «запись из N полей» |
| `map` | второй компонент | последний компонент |
| Все компоненты | `bimap` (2 функции) | `mapAll` / `nmap` (N функций) |
| Доступ | `fst()` / `snd()` | `project(i)`, индекс с 1 |
| Аппликатив/монада | есть (`ap`, `chain`, `liftA2`, Writer) | **нет** — только данные |
| Выход | `merge((a, b) => c)` | `merge((a, b, ...) => c)` |
| В массив | `toArray()` | `toArray()` / `tupleToArray` |

**Правило выбора:** нужно, чтобы первый компонент **накапливался** по ходу
цепочки (логи, счётчики, Writer-паттерн) → `Pair` (у него `chain`/`ap`).
Нужно просто **N значений строгой арности** → `Tuple`.

## 9. Полный пример: диапазон и RGB

```js
import crocks from 'crocks'
const { Tuple, nmap, tupleToArray } = crocks

const Range = Tuple(2)
const RGB = Tuple(3)

// "3-9" -> 2-Tuple( 3, 9 )
const parseRange = s => {
  const [a, b] = s.split('-').map(Number)
  return Range(a, b)
}

const range = parseRange('3-9')
console.log(range.toString())                  // 2-Tuple( 3, 9 )
console.log(range.merge((a, b) => b - a + 1))  // 7 — длина диапазона
console.log(tupleToArray(parseRange)('3-9'))   // [ 3, 9 ]

// RGB-цвет: затемнение всех каналов сразу через nmap
const darken = nmap(3)(
  x => Math.round(x * 0.8), x => Math.round(x * 0.8), x => Math.round(x * 0.8)
)
console.log(RGB(34, 139, 34).toString(), '→', darken(RGB(34, 139, 34)).toString())
// 3-Tuple( 34, 139, 34 ) → 3-Tuple( 27, 111, 27 )
```

Обрати внимание: `parseRange` **не может** случайно вернуть три значения или
одно — арность зафиксирована типом. Это и есть главное преимущество Tuple
перед «просто вернуть массив».

## 10. Резюме урока

| Инструмент | Роль |
|---|---|
| `Tuple(n)` → `T(v1, ..., vn)` | создать конструктор N-кортежей и сам кортеж (арность строгая) |
| `.project(i)` / `project(i)(t)` | доступ к элементу, **индекс с 1** |
| `.map(f)` | преобразовать только **последний** компонент |
| `.mapAll(f1..fn)` / `nmap(n)(f1..fn)(t)` | преобразовать все компоненты |
| `.merge((a, b, ...) => c)` | выход: N значений → одно |
| `.concat(other)` | поэлементное сложение полугрупп |
| `.toArray()` / `tupleToArray` | в массив (в т.ч. из функции, возвращающей Tuple) |
| `.equals(other)` / `.tupleLength()` | сравнение / длина |
