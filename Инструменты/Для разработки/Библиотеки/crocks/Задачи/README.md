# 🎯 Задачи для самопроверки

По одной задаче на каждый написанный урок. В файлах **нет решений** — только
условие, данные и **ожидаемый вывод**: напиши скрипт, запусти и сверь результат.

## Как пользоваться

1. Открой задачу рядом с уроком.
2. Создай файл, например `.mjs`, скопируй туда **данные** из раздела «Что дано».
3. Напиши код сам, используя только инструменты из раздела «Разрешённые инструменты».
4. Запусти: `node файл.mjs` и сверь вывод с разделом «Ожидаемый вывод» **посимвольно**.
5. Если совпало — урок закрыт. Если нет — вернись к разделу урока по подсказке в условии.

> 📦 Все задачи самодостаточны: в начале скрипта нужен только
> `import crocks from 'crocks'`.
>
> ⚠️ Ожидаемый вывод — это **эталон**, а не готовое решение: в самих файлах
> задач кода-ответа нет.
