# Задача к уроку 3.5 — `Arrow` 🔴

> Урок: [`../Урок-3.5-Arrow.md`](../Урок-3.5-Arrow.md)
> Цель проверки: функция как значение; композиция «затем», адаптация входа и
> разветвление входа.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Напиши скрипт, который:

1. Строит `fanout` из двух `Arrow`: «длина массива» и «сумма элементов».
   Запускает на `[1, 2, 3]` и печатает результат.
2. Композирует `inc = Arrow(x => x + 1)` и `dbl = Arrow(x => x * 2)` так, чтобы
   читалось «сначала `inc`, затем `dbl`». Запускает на `3` и печатает число.
3. Применяет к `inc` **адаптацию входа** `x => x * 10`. Запускает на `3` и
   печатает число.
4. Применяет pointfree-функцию `first` с `x => x + 100` к `Pair(1, 2)` и
   печатает результат.

## Разрешённые инструменты

`Arrow`, `fanout`, `first`, `Pair`, методы `.compose` и `.contramap`.

## Ожидаемый вывод

```text
Pair( 3, 6 )
8
31
Pair( 101, 2 )
```

## Критерии готовности

- [ ] `fanout` дал `Pair` из двух независимых результатов.
- [ ] `.compose` читается «затем» (а не как `compose`-композиция наоборот).
- [ ] `.contramap` изменил **вход** (сначала `* 10`, потом `+ 1`).
- [ ] `first` тронул только первую половину `Pair`.
