# Задача к уроку 1.4 — Ключевые методы-функции 🟢

> Урок: [`../Урок-1.4-Ключевые-методы-функции.md`](../Урок-1.4-Ключевые-методы-функции.md)
> Цель проверки: комбинировать несколько контейнеров через `liftA2` и
> каррировать функцию, чтобы она подошла для `ap`/`liftA2`.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Есть имя и фамилия, каждое — в своём `Maybe`. Собери полное имя через **одну**
операцию (не через вложенные `chain`), где функция соединения `a + ' ' + b`
сначала каррируется.

Сделай два запуска:

1. когда оба поля есть;
2. когда фамилия отсутствует (`Nothing`).

## Что дано

```js
const first = 'Иван'
const last = 'Иванов'
```

## Разрешённые инструменты

`Maybe`, `curry`, `liftA2`.

## Ожидаемый вывод

```text
Just "Иван Иванов"
Nothing
```

## Критерии готовности

- [ ] Функция соединения каррирована (иначе `liftA2` её не примет).
- [ ] При отсутствии одного поля результат — `Nothing`, а не ошибка.
- [ ] Использована одна комбинирующая операция, а не цепочка `chain`.
