# Задача к уроку 3.3 — `ReaderT` 🔴

> Урок: [`../Урок-3.3-ReaderT.md`](../Урок-3.3-ReaderT.md)
> Цель проверки: окружение **плюс** эффект (`Maybe`); отсутствие поля
> превращается в `Nothing`, а не в ошибку.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Собери `ReaderT` над `Maybe` (`ReaderT(Maybe)`) и напиши чтение порта:

1. Если в окружении есть `port` — результат должен «поднять» это значение в
   `Maybe` (`Just 8080`).
2. Если `port` отсутствует — результат должен быть `Nothing`
   (подними `Maybe.Nothing()` в `ReaderT`, а не строку-заглушку).

Дополнительно напечатай ещё две строки:

3. `ReaderT.of(1)`, к которому применён `map(x => x + 1)`, запущен на пустом
   окружении.
4. `ReaderT`, поднятый из `Maybe.Just(7)` (`lift`), на пустом окружении.

## Что дано

```js
const withPort = { port: 8080 }
const withoutPort = {}
```

## Разрешённые инструменты

`ReaderT`, `Maybe`, `ReaderT(Maybe).ask()`, `.of`, `.lift`, `map`, `chain`,
`runWith`.

## Ожидаемый вывод

```text
Just 8080
Nothing
Just 2
Just 7
```

## Критерии готовности

- [ ] Окружение и эффект `Maybe` работают **вместе** (два контекста сразу).
- [ ] Отсутствие поля — это `Nothing`, а не `Just undefined`.
- [ ] `of` — значение без окружения; `lift` — поднять готовую `Maybe`.
