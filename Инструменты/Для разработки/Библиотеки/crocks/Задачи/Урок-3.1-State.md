# Задача к уроку 3.1 — `State` 🔴

> Урок: [`../Урок-3.1-State.md`](../Урок-3.1-State.md)
> Цель проверки: `State` как «рецепт», три способа запуска и отличие
> «значение» от «состояние».
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Напиши `State`-программу `bump`, которая:

- **возвращает** текущее значение состояния,
- **увеличивает** состояние на `1`.

Запусти её с начальным состоянием `10` тремя способами и напечатай по строке:

1. `runWith(10)` → `toString()`;
2. `evalWith(10)`;
3. `execWith(10)`.

Затем напиши вторую программу `twice`, которая увеличивает состояние **дважды**
и читает его. Запусти её от `0` и напечатай:

4. `evalWith(0)`;
5. `runWith(0)` → `toString()`.

## Разрешённые инструменты

`State`, `State.get`, `State.put`, `State.modify`; `map`, `chain`;
`runWith` / `evalWith` / `execWith`.

## Ожидаемый вывод

```text
Pair( 10, 11 )
10
11
2
Pair( 2, 2 )
```

## Критерии готовности

- [ ] Различаешь три запуска: `Pair`, только значение, только состояние.
- [ ] «Вернулось старое, а состояние стало новым» — как в первом блоке.
- [ ] `twice` увеличил именно `2` раза (а не один и не три).
