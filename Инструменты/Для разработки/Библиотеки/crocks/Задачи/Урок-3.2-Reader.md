# Задача к уроку 3.2 — `Reader` 🔴

> Урок: [`../Урок-3.2-Reader.md`](../Урок-3.2-Reader.md)
> Цель проверки: вычисление, зависящее от окружения; `ask` вместо протаскивания
> конфига через аргументы.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Есть конфиг-объект. Напиши два `Reader`:

1. `greet` — читает окружение и строит строку `greeting + ', ' + name`.
2. `scale` — читает окружение и возвращает `value * factor`.

Запусти каждый на своём конфиге через `runWith` и напечатай результаты.

## Что дано

```js
const cfg1 = { greeting: 'Привет', name: 'Иван' }
const cfg2 = { factor: 3, value: 7 }
```

## Разрешённые инструменты

`Reader`, `Reader.ask()`, `map`, `chain`, `runWith`.

## Ожидаемый вывод

```text
Привет, Иван
21
```

## Критерии готовности

- [ ] Окружение берётся через `ask`, а не передаётся аргументом в обычную функцию.
- [ ] `runWith` — единственная точка запуска; без него ничего не считается.
- [ ] `scale` читает два поля окружения (одно и то же окружение).
