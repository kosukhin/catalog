# Задача к уроку 2.2 — `Tuple` 🟡

> Урок: [`../Урок-2.2-Tuple.md`](../Урок-2.2-Tuple.md)
> Цель проверки: арность в типе, `project` (индексация с **единицы**),
> `mapAll`, `merge`, мост в массив.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Возьми `t = Tuple(3)(1, 2, 3)` и напечатай по строке на каждый пункт:

1. сам кортеж (`toString()`);
2. второй компонент через `project`;
3. кортеж, где **каждый** компонент увеличен на `1` (`mapAll`);
4. сумму всех компонентов через `merge`;
5. `tupleToArray(t)` — результат напечатай **как массив**
   (то есть `console.log` без `toString()`).

## Разрешённые инструменты

`Tuple`, `project`, `mapAll`, `merge`, `tupleToArray`.

## Ожидаемый вывод

```text
3-Tuple( 1, 2, 3 )
2
3-Tuple( 2, 3, 4 )
6
[ 1, 2, 3 ]
```

## Критерии готовности

- [ ] `project(2)` вернул именно второй элемент (нумерация с единицы).
- [ ] `mapAll` получил ровно три функции (по числу компонентов).
- [ ] Последняя строка — массив, а не склеенная строка.
