# Задача к уроку 0.1 — Фундамент ФП 🟢

> Урок: [`../Урок-0.1-Фундамент-ФП.md`](../Урок-0.1-Фундамент-ФП.md)
> Цель проверки: каррирование, направление композиции и иммутабельность.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Напиши скрипт, который:

1. Объявляет функцию **трёх** аргументов `add3(a, b, c) = a + b + c` и делает её
   каррированной (`curry`). Печатает `add3(1)(2)(3)`.
2. Объявляет `inc(x) = x + 1` и `dbl(x) = x * 2`. Печатает результат
   `pipe(...)` и результат `compose(...)` для входа `3`.
3. Проверяет иммутабельность: даны `xs = [1, 2, 3]`; получив `ys` как
   `xs` плюс `4`, печатает **одной строкой** `xs.length` и `ys.length`.

Подумай, почему `pipe` и `compose` дают **разные** числа.

## Что дано

```js
// для пункта 3
const xs = [1, 2, 3]
```

## Разрешённые инструменты

`curry`, `pipe`, `compose` из crocks; для пункта 3 — обычный `concat`.

## Ожидаемый вывод

```text
6
8
7
3 4
```

## Критерии готовности

- [ ] `add3(1)(2)(3)` напечатало `6` (каррирование работает).
- [ ] `pipe` дал `8`, `compose` — `7` (порядок применён правильно).
- [ ] Исходный массив не изменился: напечатано `3 4`, а не `4 4`.
