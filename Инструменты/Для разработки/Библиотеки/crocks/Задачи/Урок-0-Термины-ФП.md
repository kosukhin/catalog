# Задача к уроку 0 — Термины ФП 🟢

> Урок: [`../Урок-0-Термины-ФП.md`](../Урок-0-Термины-ФП.md)
> Цель проверки: увидеть разницу между функтором, аппликативом и монадой на
> предикатах и убедиться, что закон тождества функтора выполняется.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Напиши скрипт, который:

1. Берёт **четыре** значения: `Identity(4)`, `Maybe.Just(4)`, `Pair('log', 4)` и
   `Arrow(x => x)`.
2. Для каждого печатает одной строкой метку и пять результатов проверок в
   порядке: `isFunctor`, `isApply`, `isApplicative`, `isChain`, `isMonad`
   (через `console.log(label, a, b, c, d, e)`).
3. Отдельной строкой печатает результат `Identity(4).map(x => x).toString()` —
   это проверка **закона тождества функтора**.

Метки в таблице должны быть ровно такими: `Identity(4)`, `Just(4)`,
`Pair('log',4)`, `Arrow(x=>x)`.

## Разрешённые инструменты

`Identity`, `Maybe`, `Pair`, `Arrow` и предикаты `isFunctor`, `isApply`,
`isApplicative`, `isChain`, `isMonad`.

## Ожидаемый вывод

```text
Identity(4) true true true true true
Just(4) true true true true true
Pair('log',4) true true false true false
Arrow(x=>x) true false false false false
Identity 4
```

## Критерии готовности

- [ ] Строки выведены в указанном порядке.
- [ ] Значения флагов совпали с эталоном (в том числе «дырки» у `Pair` и `Arrow`).
- [ ] Последняя строка показывает, что `map` с тождеством ничего не меняет.
