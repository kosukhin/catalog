# Задача к уроку 2.1 — `Pair` 🟡

> Урок: [`../Урок-2.1-Pair.md`](../Урок-2.1-Pair.md)
> Цель проверки: `Pair` несёт «значение + контекст»; `map` трогает только
> вторую половину, `concat` складывает обе, `merge` выходит из мира `Pair`.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Напиши скрипт, который:

1. Складывает попарно `Pair([1], [2])` и `Pair([3], [4])` через `concat` и
   печатает `toString()`.
2. Преобразует **обе** половины `Pair(1, 2)`: первую — в `'1!'`, вторую — в
   удвоенную десятку, и печатает результат.
3. Из `Pair(['шаг1', 'шаг2'], 42)` строит строку `42 (логи: шаг1; шаг2)` через
   `merge`.

## Разрешённые инструменты

`Pair`, `concat`, `bimap`, `merge`.

## Ожидаемый вывод

```text
Pair( [ 1, 3 ], [ 2, 4 ] )
Pair( "1!", 20 )
42 (логи: шаг1; шаг2)
```

## Критерии готовности

- [ ] `concat` сложил первые половины с первыми, вторые — со вторыми.
- [ ] `bimap` изменил сразу два компонента (как у `Either`).
- [ ] `merge` свернул пару в обычную строку.
