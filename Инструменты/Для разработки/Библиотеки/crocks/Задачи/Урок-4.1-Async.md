# Задача к уроку 4.1 — `Async` 🔴

> Урок: [`../Урок-4.1-Async.md`](../Урок-4.1-Async.md)
> Цель проверки: ленивое асинхронное вычисление, композиция, фолбэк, ошибка как
> значение и отмена. Файл должен быть `.mjs` (используется `await` верхнего уровня).
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Напиши скрипт, который печатает пять строк:

1. **Пайплайн.** Оберни в `Async.fromPromise` две «эмуляции HTTP»: загрузку
   пользователя (возвращает `{ id: 1, name: 'Ivan' }`) и его заказов
   (возвращает `[{ total: 100 }, { total: 250 }]`). Через `chain` + `map` собери
   объект `{ name, total }`, где `total` — сумма заказов. Запусти через
   `await ... .toPromise()`.
2. **Фолбэк.** Есть всегда падающий `fromNetwork('/api/user')` и «кеш»
   `Async.Resolved({ name: 'cached' })`. Сделай так, чтобы при ошибке сети
   взялся кеш, и напечатай **имя** результата.
3. **Ошибка как значение.** Из всегда падающего `Async` (ошибка —
   `new Error('timeout')`) получи сообщение `не удалось: timeout` через
   `bimap` + `coalesce` и напечатай его.
4. **Гонка.** Напечатай результат `race` между `resolveAfter(30, 'slow')` и
   `resolveAfter(1, 'fast')`.
5. **Отмена.** Создай `Async` с таймером и «чистильщиком», запусти через `fork`,
   сразу отмени и убедись, что вычисление не выполнилось: напечатай
   `ran = false` (переменная `ran` устанавливается в таймере).

## Разрешённые инструменты

`Async`, `Async.fromPromise`, `Async.Resolved`, `Async.resolveAfter`,
`.map`, `.chain`, `.alt`, `.bimap`, `.coalesce`, `.race`, `.fork`, `.toPromise`.

## Ожидаемый вывод

```text
{ name: 'Ivan', total: 350 }
cached
не удалось: timeout
race: fast
ran = false
```

## Критерии готовности

- [ ] Ни один шаг не стартует до запуска (`fork`/`toPromise`) — построение лениво.
- [ ] `chain` получает функцию, возвращающую `Async` (не значение).
- [ ] `coalesce` вызван с **двумя** функциями (иначе `TypeError`).
- [ ] Отмена действительно предотвратила запись в `ran`.
