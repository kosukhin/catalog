# Задача к уроку 1.2 — `Either` / `Result` 🟢

> Урок: [`../Урок-1.2-Either-Result.md`](../Урок-1.2-Either-Result.md)
> Цель проверки: ошибка как значение, `tryCatch` для исключений и нормализация
> обеих веток через `either`.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Напиши две вещи:

1. Функцию `checkPort(raw)`, которая проверяет, что `raw` — целое число в
   диапазоне от `1` до `65535` включительно. Успех → `Right(число)`, провал →
   `Left('порт не число')`. Напечатай результаты для `'8080'` и `'abc'`
   (через `toString()`).
2. Обёртку `parseJSON` вокруг `JSON.parse` через `tryCatch`. Напечатай строку
   для `'{"a":1}'` и для `'{bad json'`, приведя обе ветки к виду
   `'Ok ' + JSON.stringify(v)` и `'Err ' + e.name` (используй `either`).

## Ожидаемый вывод

```text
Right 8080
Left "порт не число"
Ok {"a":1}
Err SyntaxError
```

> Обрати внимание: у `Left` строковое значение печатается **в кавычках** — так
> работает `toString` у `Either`.

## Разрешённые инструменты

`Either`, `tryCatch`, `either`.

## Критерии готовности

- [ ] Валидный порт — в ветке успеха, невалидный — в ветке ошибки с текстом.
- [ ] Падающий `JSON.parse` не «вылетает», а становится значением-ошибкой.
- [ ] Обе ветки приводятся к читаемой строке через `either` (без `if` по веткам).
