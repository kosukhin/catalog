# Задача к уроку 1.1 — `Maybe` 🟢

> Урок: [`../Урок-1.1-Maybe.md`](../Урок-1.1-Maybe.md)
> Цель проверки: заменить проверки на `undefined` безопасной цепочкой `Maybe`.
>
> 💡 Решения в файле нет — только условие, данные и ожидаемый вывод.

## Условие

Напиши функцию `cityOf(user)`, которая достаёт **вложенный** город
`user.address.city`. Поля может не быть, поэтому функция не должна падать и не
должна использовать `if`/`?.` для проверки — только инструменты `Maybe`.

Для каждого пользователя напечатай **либо город, либо строку** `неизвестно`.

## Что дано

```js
const u1 = { name: 'Аня', address: { city: 'Москва' } }
const u2 = { name: 'Борис' }   // без address
```

## Разрешённые инструменты

`Maybe`, `getPath` (или `prop`), `chain`, `option`.

## Ожидаемый вывод

```text
Москва
неизвестно
```

## Критерии готовности

- [ ] Для `u1` напечатан город из вложенного объекта.
- [ ] Для `u2` напечатано `неизвестно` — без исключения.
- [ ] В коде нет `if`, `?.` и `=== undefined` для проверки полей.
