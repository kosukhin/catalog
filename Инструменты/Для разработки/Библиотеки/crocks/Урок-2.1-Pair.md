# Урок 2.1 — `Pair`: пара значений 🟡

> Цель: освоить контейнер из **двух компонентов** — «значение + сосед» — и
> главный паттерн на нём: вести рядом с вычислением **аккумулируемый контекст**
> (логи, метаданные, счётчик), а также комбинировать два таких вычисления
> (`liftA2`). Ключевые слова: `fst`, `snd`, `map`, `bimap`, `merge`, `chain`.
> Все примеры печатают результат в консоль и проверены на crocks 0.12.
>
> Документация: https://crocks.dev/docs/crocks/Pair.html

## 1. Зачем нужен Pair

`Either` — это «**или-или**»: один из двух вариантов. `Pair` — это «**и-и**»:
значение и **сосед** с ним, два компонента всегда вместе. Классические роли:

- `Pair(логи, результат)` — «значение + журнал шагов» (паттерн Writer);
- `Pair(ключ, значение)` — запись словаря (не случайно `toPairs`/`fromPairs`
   построены на Pair);
- `Pair(счётчик, значение)` — «значение + накапливаемая статистика».

Общее у всех ролей: первый компонент **прозрачно проносится** через цепочки
преобразований, пока ты работаешь со вторым. Именно это мы и увидим.

---

## 2. Создание и доступ

```js
import crocks from 'crocks'
const { Pair, fst, snd } = crocks

const p = Pair('ключ', 42)

console.log(p.toString()) // Pair( "ключ", 42 )
console.log(p.fst())      // 'ключ' — первый компонент
console.log(p.snd())       // 42 — второй (значение)

// pointfree-версии (аргумент — сам Pair)
console.log(fst(p)) // 'ключ'
console.log(snd(p)) // 42

// сравнение
console.log(Pair(1, 2).equals(Pair(1, 2))) // true
console.log(Pair(1, 2).equals(Pair(2, 2))) // false

// в обычный массив
console.log(Pair(1, 2).toArray()) // [ 1, 2 ]
```

> ⚠️ **Чего у Pair нет (проверено на crocks 0.12):**
>
> - **`Pair.of` не существует** — «обернуть одно значение» нельзя: Pair всегда
>    требует ровно два компонента, поэтому у него нет и пустого варианта;
> - **конструктора `toPair` нет в главном экспорте** — Pair создаётся только
>    `Pair(x, y)`. (Из объекта в «список пар» и обратно работают `toPairs` /
>    `fromPairs` — они вернут crocks-список Pair и объект соответственно.)

Отличие от предыдущих ADT: `Pair` — не «тип-объект» с подконструкторами
(`Maybe.Just` / `Maybe.Nothing`), а обычная **функция-конструктор** от двух
аргументов.

## 3. `map`, `bimap`, `swap`, `merge`

`map` преобразует **только второй компонент** — первый проносится как есть:

```js
import crocks from 'crocks'
const { Pair } = crocks

console.log(Pair(1, 2).map(x => x * 10).toString())
// Pair( 1, 20 ) — первый не тронут

console.log(Pair(1, 2).bimap(a => a + '!', x => x * 10).toString())
// Pair( "1!", 20 ) — оба компонента (как у Either из урока 1.2)

console.log(Pair(1, 2).swap(x => 'L' + x, x => 'R' + x).toString())
// Pair( "R2", "L1" ) — компоненты поменялись местами, функции применены
// (правая — к ставшему первым, левая — к ставшему вторым; как swap у Either)
```

`merge` — точка **выхода** из Pair-мира: берёт двухарную функцию и схлопывает
пару в одно значение:

```js
import crocks from 'crocks'
const { Pair, merge } = crocks

console.log(Pair(1, 2).merge((a, b) => a + b))   // 3
console.log(merge((a, b) => a + b)(Pair(1, 2)))  // 3 — pointfree-версия

// классика: отформатировать «логи + результат»
console.log(
  Pair(['шаг1', 'шаг2'], 42).merge(
    (logs, val) => `${val} (логи: ${logs.join('; ')})`
  )
)
// '42 (логи: шаг1; шаг2)'
```

## 4. `concat` — сложение обеих половинок

Если **оба** компонента — полугруппы (умеют `concat`: массивы, строки,
моноиды из урока 5.2), Pair тоже можно складывать покомпонентно:

```js
import crocks from 'crocks'
const { Pair } = crocks

console.log(Pair([1], [2]).concat(Pair([3], [4])).toString())
// Pair( [ 1, 3 ], [ 2, 4 ] ) — первые со-первыми, вторые со-вторыми
```

---

## 5. `ap` и `liftA2` — комбинируем два «вычисления с контекстом»

Pair — **аппликатив** (урок 1.4): можно нести функцию во втором компоненте и
применить её к значению из другого Pair. Фишка в том, что **первые компоненты
при этом складываются** (`concat`):

```js
import crocks from 'crocks'
const { Pair } = crocks

const fnP = Pair(['log'], x => x * 3)  // «функция + лог»
const valP = Pair(['шаг'], 2)          // «значение + лог»

console.log(fnP.ap(valP).toString())
// Pair( [ 'log', 'шаг' ], 6 ) — логи склеились, функция применилась
```

Тот же трюк в одну строку — `liftA2` из урока 1.4:

```js
import crocks from 'crocks'
const { Pair, curry, liftA2 } = crocks

const add = curry((a, b) => a + b)

console.log(liftA2(add, Pair([1], 10), Pair([2], 20)).toString())
// Pair( [ 1, 2 ], 30 ) — контексты сложились, значения тоже
```

Вот и «комбинирование двух ADT»: каждое вычисление несёт свой контекст, при
объединении контексты не теряются, а **накапливаются** — бесплатно.

---

## 6. `chain` — паттерн Writer: логи через всю цепочку

Главный паттерн на Pair. `chain`, как и `ap`, **складывает первые компоненты**,
а функция получает второй (значение) и возвращает новый Pair:

```js
import crocks from 'crocks'
const { Pair } = crocks

const logged = n => Pair(['взяли ' + n], n)
const doubleLogged = x => Pair(['удвоили'], x * 2)
const incLogged = x => Pair(['добавили 1'], x + 1)

const res = logged(5).chain(doubleLogged).chain(incLogged)

console.log(res.snd()) // 11 — само вычисление
console.log(res.fst()) // [ 'взяли 5', 'удвоили', 'добавили 1' ] — логи!
```

Каждый шаг пишет в «журнал», не зная о других шагах: журнал — просто первый
компонент, и `chain` автоматически склеивает записи. Никаких глобальных
переменных и побочных эффектов. Выйти — через `merge`:

```js
console.log(res.merge((logs, val) => `${val} (логи: ${logs.join('; ')})`))
// '11 (логи: взяли 5; удвоили; добавили 1)'
```

> 📖 В теории ФП это и есть монада **Writer** («писатель»): вычисление, которое
> рядом с результатом ведёт журнал. Полноценного `Writer`-ADT в crocks нет —
> Pair с массивом в первом компоненте покрывает основные сценарии.

## 7. Pair с другим ADT внутри

Второй компонент может быть любым ADT, например `Maybe`. Но помни из урока
1.4: `map` у Pair применяет функцию ко **второму компоненту как есть** — он не
«проваливается» внутрь вложенного контейнера:

```js
import crocks from 'crocks'
const { Pair, Maybe, safe } = crocks

const p = Pair('ключ', safe(x => typeof x === 'number')(5))
// Pair( "ключ", Just 5 )

console.log(p.map(x => x * 2).toString())
// Pair( "ключ", NaN ) ← ЛОВУШКА: x — это сам Just, а не число

console.log(p.map(m => m.map(x => x * 2)).toString())
// Pair( "ключ", Just 10 ) — правильно: сначала map внутрь Maybe

// chain
console.log(p.chain(x => Pair('doubled', x * 2)).toString())
```

Двойной `map(map(f))` — обычное дело при вложенных контейнерах: внешний `map`
заходит в Pair, внутренний — в Maybe.

## 8. Резюме урока

| Инструмент | Роль |
|---|---|
| `Pair(x, y)` | создать пару (только так — `Pair.of`/`toPair` в 0.12 нет) |
| `.fst()` / `.snd()` и `fst(p)` / `snd(p)` | доступ к компонентам |
| `.map(f)` | преобразовать **только второй** компонент |
| `.bimap(fL, fR)` | преобразовать оба |
| `.swap(fL, fR)` | поменять компоненты местами |
| `.merge((a, b) => c)` / `merge(f)(p)` | выход: пара → одно значение |
| `.concat(other)` | покомпонентное сложение (обе части — полугруппы) |
| `.ap(pair)` / `liftA2(f, p1, p2)` | аппликатив: первые складываются, значения применяются |
| `.chain(f)` | Writer: первые складываются, вторая передаётся в шаг |
